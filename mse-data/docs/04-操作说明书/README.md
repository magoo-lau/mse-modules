# 04 操作说明书 —— 总览与使用指南

> MSE-Data 多租户数据中台**分角色操作说明书**总览。每本手册面向一个业务岗位，讲清「这个岗位能做什么、在哪个页面做、按什么顺序做」。
> 功能全景见 [01-功能规划](../01-功能规划.md)；角色授权设计依据见 [03-角色规划](../03-角色规划.md)。手册描述以当前系统实际界面为准。

## 一、手册索引（按岗位领取）

| 手册 | 角色（建议编码） | 数据范围 | 一句话定位 |
| --- | --- | --- | --- |
| [01-数据管理员](01-数据管理员.md) | data_admin | 全部 | 数据源接入、同步任务与依赖编排、质量规则、查询白名单，全模块管理兼 API 审批 |
| [02-数据分析师](02-数据分析师.md) | data_analyst | 全部（只读为主） | 数据地图找数、元数据与血缘、采样预览与导出、AI 问数 |
| [03-数据服务开发者](03-数据服务开发者.md) | data_developer | 全部 | API 定义与试运行、提交审批、调用方应用与授权、开放调用对接 |

> 角色分配：本系统**无预置角色**，由租户管理员在基座「组织管理 → 角色管理」按上表编码**自行创建**角色并授权（权限点勾选清单见 [03-角色规划](../03-角色规划.md) 第五节），再授予员工。一个员工可兼多角色，权限取并集；所有人可见的菜单还受租户「套餐」勾选的上界约束。租户超管无需角色即拥有全部权限。

## 二、进入系统

1. 用企业账号登录**基座门户**（浏览器访问门户地址）。
2. 登录后在左侧导航找到「**数据中台**」分组目录，展开即见本系统全部页面菜单（数据概览、数据源管理、数据集成、数据地图、数据服务、质量监控、查询白名单）。菜单按你的角色授权显示——看不到某个菜单表示该角色未授权或套餐未包含。
3. 界面为微前端嵌入运行：导航、登录态、深浅色主题均由基座统一管理，数据中台页面内不再单独登录。

## 三、系统业务全景（数据链路闭环）

```
登记数据源（外部业务库 / 内置中台库）
  → 数据集成：建同步任务（整表 / 自定义 SELECT → ODS 贴源表）
      全量清空重灌 / 增量水位；cron 调度；前置任务级联（防环，链深 20）
  → 数据地图：登记贴源层 / 登记中台库业务表 / 采集外部源
      表详情 + 上下游血缘 + 采样预览 + 导出 xlsx
  → 数据服务：SELECT 封装 API（:param 参数化）→ 提交审批 → 审批通过发布
      调用方应用（AppKey/Secret）→ 授权（批量 + 过期时间）
  → 第三方系统签名调用 /openapi/data/{path}
  → 质量监控：对 ODS 表建规则 → 检测报告（通过率/坏数据）
  → 数据概览：资产计数 / 今日调用量 / 未通过规则
```

## 四、通用操作（所有页面一致）

### 4.1 列表与筛选

- 筛选区在列表上方：文本框输入后按**回车**或点「查询」触发；下拉筛选**选中即自动刷新**；点清除图标恢复全部。
- 列表分页显示（每页 10 条）；大量数据请配合筛选缩小范围。

### 4.2 表单与确认

- 新建/编辑均为弹窗表单，`*` 标注必填项；口令类输入编辑时**留空表示不修改**。
- 危险操作（删除数据源/任务/API/白名单表）弹出确认框并说明影响；确认后执行。
- 下拉可搜索（filterable）且支持**手输**（allow-create）：元数据未采集的表名/列名可直接输入。

### 4.3 状态自动刷新

- 同步任务「日志」弹窗在任务执行中**每 2 秒自动刷新**，出现终态（成功/失败）后停止。
- 数据源「连通性」列显示最近一次测试结果（正常/失败悬浮原因/未测试）。

### 4.4 外观

深浅色模式与主题色跟随基座门户设置（门户右上角切换），数据中台页面自动跟随，无需单独设置。

## 五、状态字典速查（界面标签的准确含义）

| 业务对象 | 状态枚举 |
| --- | --- |
| 数据源 | 启用 / 停用；连通性：正常 / 失败（悬浮原因）/ 未测试 |
| 同步任务 | 启用 / 停用；模式：全量 / 增量；调度：cron 表达式 / 手动 |
| 同步日志 | 执行中（running）→ 成功（success）/ 失败（failed）；触发：手动 / 调度 |
| 数据 API | 草稿 → 待审批 → 已发布 / 已驳回 →（编辑自动打回草稿）；已发布可下线（回到草稿） |
| 调用方应用 | 启用 / 停用；AppSecret 仅创建/重置时展示一次 |
| API 授权 | 永久（过期时间留空）/ 限时（到期即拒，列表红色「已过期」标识） |
| 质量规则 | 启用 / 停用；最近结果：通过 N% / 未通过 / 未执行；触发：手动 / 调度 |
| 元数据分类 | 源库表（source）/ 贴源表（ods） |
| 白名单表 | 启用 / 停用（停用与移出等效：中台库通道立即拒绝查询） |

## 六、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 左侧看不到「数据中台」菜单 | 租户套餐未勾选数据中台页面菜单（平台端「套餐管理」），或该用户角色未授权菜单。 |
| 看得到菜单但看不到某些按钮 | 按钮按权限显隐：无该操作权限的角色不显示按钮（如只有「查询」无「新建任务」）。找租户管理员补授权。 |
| 「中台库」下拉选项是灰的/没有 | 正常：内置「中台库（内置 · 自动租户隔离）」是固定首项，始终可选；其余为已启用的外部数据源。 |
| 保存数据源被拒绝 | 大概率把平台主库坐标当外部数据源登记了（防呆护栏）。中台库取数请在「数据集成」任务来源中选内置「中台库」。 |
| 同步任务执行报「查询结果必须带出 tenant_id 列」 | 自定义查询把含租户列表投影掉了。把 tenant_id 加回 SELECT 列表即可。 |
| 同步任务前置任务保存报错 | 依赖成环（A 的前置是 B、B 的前置又是 A）或超链深上限 20。调整依赖方向。 |
| 数据地图里搜不到表 | 先做元数据采集：「登记贴源层」「登记中台库业务表」或按数据源「采集」；未采集的表在任务表单里也可手输。 |
| API 调用返回 403「授权已过期」 | 授权设置了过期时间且已到期。数据服务开发者在「调用方应用 → 授权」改期或重新授权。 |
| API 编辑后调用方报 404 | 编辑已发布 API 会自动打回草稿并下线。需重新提交审批、通过发布后调用方才能恢复调用。 |
| 调用方应用密钥丢了 | AppSecret 仅展示一次。在「调用方应用」点「重置密钥」重新生成（旧密钥立即失效，通知消费方更新）。 |
| 质量规则目标表选不到业务表 | 质量模块仅作用于中台贴源层（`ods_` 表）。要检业务表请先把业务数据同步进 ODS。 |
| AI 问数查不到某张业务表 | 中台库通道默认只认 `ods_` 表。请数据管理员在「查询白名单」登记该表（须含 tenant_id 列）。 |
| 列表里看不到别人的任务/API | 数据按租户隔离：不同租户互不可见，属正常设计。同租户内所有授权角色共享数据。 |

## 七、阅读建议

- 新岗位上手：先读本手册第二节、第三节建立全局认识，再读对应角色手册的「典型流程」。
- 遇到具体按钮/字段疑问：查角色手册的分步操作，按钮文字与界面一致，可直接对照。
- 状态流转拿不准：查第五节状态字典。
- 第三方系统对接（签名、参数、返回结构）见 [03-数据服务开发者](03-数据服务开发者.md) 第四节。
