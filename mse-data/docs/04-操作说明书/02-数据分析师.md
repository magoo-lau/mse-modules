# 02 数据分析师操作手册

> 角色：`data_analyst`（建议编码）｜数据范围：本租户全部数据（页面以只读与导出为主）｜菜单：数据概览、数据集成（只读）、数据地图、质量监控（只读）。
> 定位：**找数、看数、取数**——用数据地图检索与理解本租户的数据资产，跟踪同步与质量状况，用导出和 AI 问数拿到分析所需的数据。

## 一、职责与页面清单

| 职责 | 页面 |
| --- | --- |
| 数据资产全景（资产计数、今日调用量、最近动态） | 数据概览 |
| 检索表、看表结构与注释、上下游血缘 | 数据地图 |
| 采样预览、导出 xlsx | 数据地图 |
| 了解同步任务运行情况（只读） | 数据集成 |
| 跟踪质量规则结果与检测报告（只读） | 质量监控 |
| AI 问数（经 mse-ai 智能体自然语言查数） | mse-ai 对话工作台 |

> 你**没有**的操作：新建/编辑数据源与同步任务、元数据采集、质量规则编辑与执行、数据服务 API 管理。这些由数据管理员 / 数据服务开发者完成。

## 二、数据概览（每天先看这里）

> 路径：数据中台 → **数据概览**。

- **八张统计卡**：注册数据源、启用中同步任务、贴源层表（ODS）、已采集源表、已发布数据 API、今日调用次数、质量规则、未通过规则。
- **最近同步任务**：哪些任务最近在跑、行数与时间。
- **最近 API 调用**：开放调用成功/失败、行数、耗时。
- 关注点：「未通过规则」> 0 时先去质量监控看哪张表出问题，再决定是否影响你的分析口径。

## 三、数据地图（核心工作区）

> 路径：数据中台 → **数据地图**。

### 3.1 找表

1. 关键字框输入**表名/注释关键字**，回车检索。
2. 可按分类筛选：**源库表**（外部源与中台库业务表）/ **贴源表（ODS）**——做分析优先看 ODS 贴源表。
3. 找不到表：该表可能未采集。请数据管理员执行「登记贴源层 / 登记中台库业务表 / 采集」。

### 3.2 看表（详情抽屉）

点行内「**详情**」，抽屉内依次有：

1. **表信息**：表名、分类（贴源层/源库）、注释、采集时间。
2. **列清单**：列名、类型、可空、注释——理解字段含义的第一手材料。
3. **上下游血缘**：「上游来源（同步自）」告诉你要追根溯源去哪张源表；「下游去向（被同步至）」告诉你这张表被哪些二次加工任务引用（改口径前先看下游）。
4. **采样预览**：点「采样」拉取限行数样本数据，直接确认数据内容与质量。

### 3.3 导出数据

1. 行内点「**导出**」，系统把该表数据导出为 **xlsx** 文件自动下载（上限 5 万行；默认前 1 万行，更大范围请分批或让管理员评估）。
2. 导出文件名即表名；打开后按列注释对齐口径即可开始分析。

### 3.4 血缘追根（典型场景）

「这张 ODS 订单表的数据从哪来？」→ 数据地图搜该表 → 详情 → 上游来源列给出源表与同步任务名 → 到「数据集成」看该任务的来源数据源与运行日志，确认数据新鲜度（最近执行时间、同步行数）。

## 四、数据集成（只读参考）

> 路径：数据中台 → **数据集成**。

- 列表看任务的：来源 → 目标 ODS 表、模式（全量/增量）、调度（cron/手动）、最近行数、最近执行时间。
- 「**日志**」可查每次执行的状态、行数、水位与耗时——判断「数据到没到、到多少」。
- 你不能执行/编辑任务；发现数据缺失联系数据管理员（报任务名与期望时间点）。

## 五、质量监控（只读参考）

> 路径：数据中台 → **质量监控**。

- 「质量规则」页签：看规则的目标表、类型、最近结果（通过 N% / 未通过）与最近执行时间。
- 「检测报告」页签：历史报告的总行数 / 坏数据 / 通过率 / 触发方式。
- 用法：分析前先查目标表的规则结果——「通过率 100%」的表可放心用；「未通过」的表注意坏数据可能影响结论。

## 六、AI 问数（自然语言查数）

> 入口：mse-ai 平台的对话工作台（AI 平台侧授权；本系统无独立页面）。

1. 在 mse-ai 创建的「问数」智能体里用自然语言提问，例如「查一下 ods_sys_config 里 dark 相关的配置」「本租户有哪些数据源」。
2. 智能体经数据中台的受控工具取数：先检索表/列元数据，再执行**只读 SQL**（自动按租户过滤、限行数）。
3. 可查范围：`ods_` 贴源表 + 本租户白名单业务表（独立库租户自动路由到租户库）。查不到业务表时请数据管理员在「查询白名单」登记。
4. 提问技巧：尽量带上**表名或业务关键词**（如「订单」「配置」）；对返回结果有疑问时用数据地图核对表结构与采样。

## 七、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 搜不到某张表 | 未采集元数据。请数据管理员采集（登记贴源层/中台库业务表/指定数据源）。 |
| 「详情」能看但没有「导出」按钮 | 角色未授 `data:meta:export`（数据导出）。找租户管理员补授权。 |
| 采样/导出报错 | 目标表可能刚重建或无数据；刷新后重试，仍报错联系数据管理员看同步日志。 |
| 血缘里没有上下游 | 该表还没有被同步任务引用（贴源表未被二次加工、或源表尚未建任务）。 |
| 看不到「新建任务」等按钮 | 正常：分析师角色无编辑权限，属权限设计而非故障。 |
| AI 问数返回「仅允许 ods_ 前缀贴源表或白名单业务表」 | 中台库通道防护栏。请数据管理员把目标业务表加入「查询白名单」后重试。 |
| 导出行数不足 5 万 | 导出上限保护。需要全量数据时与数据管理员协商分批或其他通道。 |
