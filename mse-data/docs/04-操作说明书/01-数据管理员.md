# 01 数据管理员操作手册

> 角色：`data_admin`（建议编码）｜数据范围：本租户全部数据｜菜单：「数据中台」全部分组下的所有页面。
> 定位：数据资产域的管理员——负责**数据源接入**、**数据集成同步与依赖编排**、**元数据采集**、**质量规则**、**查询白名单**，并对全部模块拥有完整操作权限（含数据服务审批）。**不负责**基座侧的用户/角色/套餐管理（那是租户管理员的事）。

## 一、职责与页面清单

| 职责 | 页面 |
| --- | --- |
| 外部业务库登记、连通性测试、启停 | 数据源管理 |
| 同步任务建管（整表/自定义查询、全量/增量、cron）、前置任务依赖编排、运行日志排查 | 数据集成 |
| 元数据采集（贴源层/中台库业务表/外部源） | 数据地图 |
| 质量规则建管与执行、报告跟踪 | 质量监控 |
| 中台库通道直查白名单维护 | 查询白名单 |
| 数据服务全模块管理兜底（含 API 审批） | 数据服务 |

## 二、数据源管理（接入第一步）

> 路径：数据中台 → **数据源管理**。

### 2.1 登记外部数据源

1. 点「**新增数据源**」：名称、类型（MySQL / 达梦 DM8 / 金仓 KingbaseES / PostgreSQL）、主机、端口、库/Schema、追加参数（JDBC 参数，可空）、用户名、口令、备注。
2. 保存后行内点「**测试**」验证连通性；列表「连通性」列显示最近结果，失败原因悬浮可见。
3. 口令 AES-GCM 加密落库；**编辑时口令留空表示不修改**。

注意事项：

- **只能登记租户自有/外部业务库**。误填平台主库坐标会保存被拒（提示改用内置「中台库」来源）——这是防呆护栏，不是故障。
- 停用数据源后，新建同步任务/API 的数据源下拉不再出现它；删除前确认没有任务/API 在用（提示「使用它的同步任务与 API 将失效」）。

### 2.2 内置中台库（无需登记）

「中台库（内置 · 自动租户隔离）」是系统内置来源（自动按租户过滤），在**数据集成**任务来源下拉中始终存在，不需要也不可能在数据源管理里登记。

## 三、数据集成（同步任务与依赖编排）

> 路径：数据中台 → **数据集成**。列表展示任务、来源、目标 ODS 表、模式、调度、前置任务、最近行数与执行时间。

### 3.1 建议的初始化顺序

1. （可选）先在数据地图「**登记中台库业务表**」，让任务表单的源表/水位列有下拉可选（未登记也可手输）。
2. 新建第一批任务：来源业务表 → 目标 ODS 贴源表。
3. 对需要二次加工的表建级联任务：来源选**中台贴源层**的 `ods_` 表，前置任务设为第一批任务。

### 3.2 新建任务分步

1. 点「**新建任务**」：任务名称。
2. **来源数据源**：选内置「中台库（内置 · 自动租户隔离）」或某个已启用外部数据源。
3. **来源类型**：
   - **整表**：源表下拉选择（或手输），全表搬运。
   - **自定义查询**：仅 SELECT、不支持参数占位；引用含租户列的表时**结果必须带出 tenant_id 列**，否则执行报错。
4. **目标 ODS 表**：`ods_` 开头小写（如 `ods_sys_config`）；表不存在引擎**自动建表**（自带 tenant_id 列）。
5. **同步模式**：全量（清空重灌）/ 增量（水位）——增量需选**水位列**（时间戳或自增 ID，如下拉为空可手输），水位由引擎回写、重跑幂等。
6. **调度 cron**：可空（仅手动）；Spring cron 表达式组件带预览。
7. **前置任务**：选「无」或某个任务——**前置成功后自动级联执行本任务**。
8. 保存后行内「**执行**」手动触发，弹窗看日志（执行中每 2 秒自动刷新）。

### 3.3 依赖编排规则（防环）

- 每个任务至多一个前置任务，可串成链：A → B → C（A 成功跑 B，B 成功跑 C）。
- **链深上限 20**；把前置设成自己的下游会报「依赖成环」，无法保存。
- 链条只在**手动执行头部任务**或 cron 触发头部任务时级联；中途失败不再向后传递，日志里看失败原因。

### 3.4 运行日志排查

- 「日志」弹窗按任务展示历史执行：触发方式（手动/调度）、状态（执行中/成功/失败）、行数、前后水位、耗时、错误信息。
- 失败常见原因：源库不可达（先去数据源管理点「测试」）、自定义查询投影掉了 tenant_id、水位列类型不支持、目标 ODS 表结构冲突（源结构变更后建议换新目标表重建）。

## 四、元数据采集（数据地图）

> 路径：数据中台 → **数据地图**。采集是「让系统认识表」的动作，全归管理员。

- 「**登记贴源层**」：把全部 `ods_` 贴源表登记为元数据（同步任务跑过后执行一次即可）。
- 「**登记中台库业务表**」：把主库业务表登记为来源元数据——**同步任务表单的源表/水位列下拉即来自这里**。
- 「**采集**」指定数据源：下拉选外部数据源后点击，采集其表/列/注释。
- 采集后可在表「详情」里查看列清单与上下游血缘；「采样」预览数据；「导出」下载 xlsx（分析师常用，见 02 号手册）。

## 五、质量规则

> 路径：数据中台 → **质量监控**。质量检测**仅作用于中台贴源层（ods_ 表）**。

1. 点「**新建规则**」：数据源固定选「中台贴源层」→ 目标表（`ods_` 表）→ 规则类型：
   - **非空检测**：检测列不允许空值。
   - **唯一检测**：检测列不允许重复。
   - **数值区间**：检测列须在最小值~最大值之间。
   - **枚举值**：检测列取值须在合法值清单内（逗号分隔）。
   - **自定义坏数据 SQL**：仅 SELECT，返回的每一行视为一条坏数据（走 SQL 防护）。
   - **行数波动**：对比上次基线行数，超阈值百分比判不通过。
2. 配调度 cron（可空=仅手动），行内「**执行**」立即检测。
3. 「报告」页签看历史：总行数 / 坏数据 / 通过率 / 耗时；规则列表回写「最近结果」。
4. 质量不通过的表先修源数据再重跑同步任务，报告自然翻绿。

## 六、查询白名单

> 路径：数据中台 → **查询白名单**。中台库通道默认只放行 `ods_` 贴源表；要让数据服务/AI 工具直查某张**业务表**，在这里登记。

1. 点「**新增白名单表**」：表名（自动转小写）+ 备注。表必须含 `tenant_id` 列，否则执行时报「缺少 tenant_id 列」拒绝。
2. 查询时自动按租户过滤；**移出白名单立即生效**（该表随即被拒）。
3. 独立库租户：白名单业务表自动路由至租户专属库；`ods_` 与白名单表**不能混在同一条查询**里（提示拆分为两条查询）。

## 七、数据服务（含审批兜底）

> 日常建 API / 建应用 / 授权由数据服务开发者操作（见 03 号手册）；管理员持有全量权限，重点两件事：

- **API 审批**：「数据服务 → API 管理」，待审批行点「**审批**」→ 通过并发布 / 驳回（填意见）。审批通过前 API 无法被开放调用；已发布 API 被编辑会自动打回草稿，需重新审批。
- **调用审计**：「调用日志」页签看每次开放调用的 API、参数、行数、耗时、结果与来源 IP，异常调用（大量失败/陌生 IP）及时停用对应应用。

## 八、管理员注意事项

1. **地基先行**：数据源口令、主机坐标错了会传导到同步任务、质量规则全线；投产前逐个「测试」。
2. **编码小写**：ODS 目标表与白名单表名统一小写；目标表必须 `ods_` 前缀。
3. **删除有连锁**：删数据源会使引用它的任务/API 失效；删任务保留 ODS 表数据（可先导出留档）。
4. **全量重灌有清空动作**：全量任务执行时会清空目标 ODS 表再灌入（严格带租户条件、禁 TRUNCATE），确认无下游正在消费再执行。
5. **调度为应用内存态**：停机期间错过的 cron 时点只补跑一次；分布式部署需外置调度（见工程 README 已知边界）。
