> mse-data 功能总纲。配套文档：[02-权限规划](02-权限规划.md)（每个功能点的权限码）、[03-角色规划](03-角色规划.md)（谁能用）。

## 一、模块总览与核心业务闭环

| # | 模块 | 页面菜单（menu_id） | 一句话定位 |
| --- | --- | --- | --- |
| 1 | 数据概览 | 数据概览（441） | 资产计数、今日调用量、质量概况、最近同步与调用记录 |
| 2 | 数据源管理 | 数据源管理（442） | 注册外部业务库（MySQL/达梦/金仓/PostgreSQL），口令加密、连通性测试、独立连接池 |
| 3 | 数据集成 | 数据集成（443） | 同步任务：整表/自定义 SELECT → ODS 贴源表，全量/增量、cron、前置任务依赖编排、运行日志与血缘 |
| 4 | 数据地图 | 数据地图（444） | JDBC 元数据采集（表/列/注释）、关键字检索、表详情、采样预览、ODS 导出 xlsx、上下游血缘 |
| 5 | 数据服务 | 数据服务（445） | 把 SELECT 封装为开放 HTTP API：审批流、appKey+签名、授权/限流、调用审计（三页签：API 管理/调用方应用/调用日志） |
| 6 | 数据质量 | 质量监控（446） | 六类质量规则（cron+手动）、检测报告（总行数/坏数据/通过率） |
| 7 | 查询白名单 | 查询白名单（447） | 中台库通道（datasourceId=0）可直查业务表的租户自持白名单 |
| 8 | AI 智能查询 | 嵌入 mse-ai（无独立页面） | mse-ai 反向集成工具 `data_query`：元数据检索 + 受控只读 SQL，供智能体「问数」 |

**核心业务闭环**：

```
登记数据源（外部业务库 / 内置中台库）
  → 数据集成同步任务（整表 / 自定义 SELECT）
  → 贴源入 ODS（自动建表，附 tenant_id；全量清空重灌 / 增量水位）
  → （可选）前置任务依赖编排：A 成功 → 级联触发 B（防环校验，链深上限 20）
  → 数据地图：元数据采集（登记贴源层 / 登记中台库业务表 / 采集外部源）
      表详情 + 上下游血缘 + 采样预览 + 导出 xlsx
  → 数据服务：SELECT 封装为 API（:param 参数化）→ 提交审批 → 审批通过发布
  → 调用方应用（appKey/AppSecret）→ 授权 API（批量 + 过期时间）
  → 第三方系统签名调用 /openapi/data/{path}
  → 数据质量：对 ODS 表建规则（非空/唯一/区间/枚举/自定义 SQL/行数波动）→ 检测报告
  → 概览监控：资产计数 / 今日调用量 / 未通过规则 / 最近同步与调用
```

## 二、数据源管理（442）

外部数据源按**数据源级隔离**：仅本租户登记的数据源可用；内置「中台库（datasourceId=0）」走行级隔离通道。

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| 数据源登记 | 类型 MySQL / 达梦 DM8 / 金仓 KingbaseES / PostgreSQL；主机、端口、库/Schema、JDBC 追加参数、账号口令（口令 AES-GCM 加密落库，编辑留空表示不修改） | 数据管理员 |
| 连通性测试 | 行内「测试」即测即报；列表展示最近测试时间/结果/失败原因（悬浮可见） | 数据管理员 |
| 启停与删除 | 停用后新任务/新 API 不可选；删除前提示「使用它的同步任务与 API 将失效」 | 数据管理员 |
| 主库防呆护栏 | 误填平台主库坐标（host/port/库名，localhost≈127.0.0.1 归一比对）保存即拒绝，提示改用内置「中台库」来源；存量命中数据源执行期同样拒绝 | 数据管理员 |
| 独立连接池 | 每个注册数据源独立 Hikari 池（默认单池上限 8、闲置 300 秒回收，`mse.data.pool.*` 可调） | —（平台行为） |

## 三、数据集成（443）

同步目标是中台 **ODS 贴源层**：目标表 `ods_` 前缀小写，不存在时引擎自动建表并附 `tenant_id` 列；ODS 写入清理严格带 `tenant_id` 条件，禁止 TRUNCATE。

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| 来源数据源 | 下拉首项为内置「中台库（内置 · 自动租户隔离）」（共享库业务表取数的合法通道）；其余为已启用外部数据源 | 数据管理员 |
| 整表同步 | source_type=table：源表下拉来自元数据（未采集可直接手输），全表搬运 | 数据管理员 |
| 自定义查询同步 | source_type=sql：仅 SELECT、不支持参数占位；引用含租户列的表时结果必须带出 `tenant_id` 列，否则执行拒绝 | 数据管理员 |
| 全量 / 增量 | full=清空重灌；incr=水位增量（时间戳/自增 ID 列，水位由引擎回写、重跑幂等） | 数据管理员 |
| cron 调度 + 手动执行 | Spring cron 表达式（带预览组件），留空=仅手动；行内「执行」触发手动运行并弹日志窗（执行中每 2 秒自动刷新） | 数据管理员 |
| 前置任务依赖编排 | 指定前置任务（dep_job_id）：前置成功后级联触发本任务；**防环校验、链深上限 20**——把前置设成下游任务会报「依赖成环」 | 数据管理员 |
| 运行日志 | 每次执行一行：触发方式（手动/调度）、状态（执行中/成功/失败）、行数、前后水位、耗时、错误信息 | 数据管理员 |
| 任务级血缘 | 每个任务自动登记「源表 → ODS」血缘；按表名双向查询（数据地图表详情展示上下游） | 数据管理员 |

**取数通道与隔离语义**（两条通道，行为不同）：

| 通道 | 标识 | 隔离语义 |
| --- | --- | --- |
| 内置中台库 | datasourceId=0 | 行级：自动按 `tenant_id` 过滤；默认仅放行 `ods_` 贴源表 + 本租户「查询白名单」业务表；同步来源档业务表执行期探测含 `tenant_id` 列时强制只取本租户行 |
| 外部数据源 | `dat_datasource`（id>0） | 数据源级：仅本租户登记的数据源可用，不注入租户条件；同步源表若自带 `tenant_id` 列自动按当前租户过滤 |

## 五、数据服务（445）

把 SELECT 封装为开放 HTTP API（`/openapi/data/{path}`），页内三页签：**API 管理 / 调用方应用 / 调用日志**。

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| API 定义 | 名称、开放路径（租户内唯一）、数据源（中台贴源层 / 外部源）、SQL 模板（仅 SELECT，`:name` 参数化绑定 → JDBC `?`）、参数定义 JSON、分页开关、行数上限（默认 1000）、超时（默认 10s）、限流（次/分钟，0=全局默认 60） | 数据服务开发者 |
| 发布审批流 | 草稿 → 待审批 → 已发布 / 已驳回 → 下线，全程留痕（提交/通过/驳回/下线记录操作人与意见）；`mse.data.service.approval-enabled=false` 可关（保存即发布）；**已发布 API 一旦编辑自动打回草稿重新审批** | 开发者提交 / 审批人审批 |
| 试运行 | 任意状态下传参数 JSON 执行，返回行数/耗时/结果表格，发布前验证 SQL 与参数 | 数据服务开发者 |
| 调用方应用 | 新建应用生成全局唯一 AppKey + AppSecret（密钥仅展示一次，可重置）；启停/删除 | 数据服务开发者 |
| API 授权 | 按 App 多选 API **批量授权**，过期时间留空=永久；已授权重复授权即刷新过期时间；列表支持单行「改期」、过期红色标识、收回 | 数据服务开发者 |
| 签名调用 | `HMAC-SHA256(appSecret, appKey\n timestamp\n nonce)` 十六进制小写；头 `X-App-Key/X-Timestamp/X-Nonce/X-Sign`；nonce 防重放、时间戳窗口默认 300 秒 | 消费方系统 |
| 执行防护 | jsqlparser 校验仅 SELECT（拒绝派生表/UNION/WITH）；中台库通道自动注入 `tenant_id` 谓词（每张 JOIN 表都注入）；超时/行数上限；Redis 限流 | —（平台行为） |
| 调用审计 | 每次调用记录 API/应用/参数/行数/耗时/结果/错误/来源 IP | 数据管理员 / 开发者 |
| 开放调用到期控制 | 授权过期后开放调用即拒绝（403「授权已过期」） | —（平台行为） |

## 六、数据质量（446）

质量模块**仅作用于中台贴源层**（仅 `ods_` 表、仍在主库执行——避免独立库租户在主库跑出空数据的误导性报告；不扩展查询白名单）。

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| 六类规则 | 非空（not_null）/ 唯一（unique）/ 数值区间（range）/ 枚举值（enum）/ 自定义坏数据 SQL（custom_sql，仅 SELECT，返回行即坏数据，走 jsqlparser 防护）/ 行数波动（对比上次基线，阈值百分比） | 数据管理员 |
| cron 调度 + 手动执行 | Spring cron（留空=仅手动）；行内「执行」立即检测 | 数据管理员 |
| 检测报告 | 总行数 / 坏数据行数 / 通过率 / 耗时 / 触发方式；规则列表回写最近结果与通过率 | 数据分析师 |
| 启停管理 | 规则启停开关，停用后不再调度 | 数据管理员 |

## 七、查询白名单（447）

中台库通道（datasourceId=0）默认只放行 `ods_` 前缀贴源表；本页把允许直查的**中台库业务表**登记进来（表名小写归一化、同表判重、启停开关），供数据服务 API 与 AI 工具 `data_query` 共用。

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| 白名单登记 | 表名（自动转小写）+ 备注；执行前在目标库探测须含 `tenant_id` 列（缺列/表不存在拒绝执行） | 数据管理员 |
| 执行路由 | 共享库租户：纯 ods_ 与白名单查询均落主库；独立库租户：白名单业务表路由至其租户专属库；**ods_ 与白名单混查拒绝**（提示拆分为两条查询） | —（平台行为） |
| 移出即拒 | 移出白名单后中台库通道立即拒绝查询该表 | 数据管理员 |

## 八、AI 智能查询（嵌入 mse-ai，无独立页面）

mse-ai 智能体平台反向集成工具 **`data_query`**（`RemoteAiTool`，一服务一工具、action 分发），供智能体「问数」受控取数：

| action | 供数内容 | 说明 |
| --- | --- | --- |
| `meta_search` | 检索表/列元数据 | 支持按**表名**查列清单（推荐），也可按关键字或元数据编号 |
| `execute` | 受控只读 SQL 查询 | SQL 防护 + 租户条件注入 + 限行数；编号一律以**字符串**回传（防模型抄写长整型出错） |
| `datasource_list` | 数据源清单 | 中台库 + 当前租户已启用数据源，含中台库白名单表清单 `allowedTables` |

红线：模型生成的 SQL 不直接落库——统一经 `ApiQueryExecutor`（与数据服务共用执行通道）；查不到表时返回引导性错误（提示改用 keyword 重检）。使用方式见 [03-角色规划](03-角色规划.md) 第四节与 [04-操作说明书](04-操作说明书/README.md) 数据分析师手册。

## 九、开放 API（/openapi/data）专节

**自持签名通道**（与本工程开放契约通道并存）：

- 端点：`POST /openapi/data/{path}`（亦支持 GET），path 为 API 定义中的开放路径；网关白名单 `/openapi/data/**` 免登录，鉴权全靠签名。
- 请求头：`X-App-Key` / `X-Timestamp`（秒级时间戳）/ `X-Nonce`（随机串防重放）/ `X-Sign`。
- 签名：`HMAC-SHA256(appSecret, appKey + "\n" + timestamp + "\n" + nonce)` 十六进制小写。
- 请求体：`{"params":{"...":...},"pageNum":1,"pageSize":20}`（分页仅 API 开启分页时生效）。
- 返回：`{"code":0,"message":"ok","data":{"columns":[...],"rows":[...],"hasMore":false,"costMs":12}}`。
- 防护链：应用启停 → 授权校验（含过期）→ 签名校验（时间戳窗口默认 300 秒 + nonce）→ API 发布状态 → 限流（Redis，API 级 qps_limit，0=全局默认 60/分钟）→ SQL 防护与租户谓词注入 → 超时/行数上限。

**mse-open 统一窗口**（新接入建议）：`data-api` 契约 `RemoteDataApiService.invoke`（apiPath + params + 可选分页，JSON 进出），经 `DataOpenApiContributor` 自注册 mse-open 目录，对外路径 `POST /open/api/data/api/invoke`（凭证/授权/限流/审计由开放平台完成）。
