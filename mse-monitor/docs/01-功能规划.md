# 01 功能规划 —— 功能模块与功能点

> mse-monitor 功能总纲。配套文档：[02-权限规划](02-权限规划.md)（每个功能点的权限码）、[03-角色规划](03-角色规划.md)（谁能用）。
> 功能以工程 README 与实际 Controller/页面为准；「主要角色」见 [03-角色规划](03-角色规划.md)。

## 一、模块总览

| # | 模块 | 页面菜单（menu_id） | 一句话定位 |
| --- | --- | --- | --- |
| 1 | 监控总览 | 监控总览（491） | 统计卡 + 目标状态网格 + 最近告警，全局健康一屏掌握 |
| 2 | 监控目标管理 | 监控目标（492） | 8 类监控对象的接入（CRUD）、启停、立即检测 |
| 3 | 指标采集与趋势 | 目标详情（492 内） | 拉模式周期采样、echarts 趋势（近 1h/24h/7d） |
| 4 | JVM 监控 | 监控目标（492，jvm 类型） | 堆/非堆/线程/GC/进程 CPU，零侵入读 metrics |
| 5 | 慢SQL 监控 | 监控目标（492，slowsql 类型） | 慢语句列表与新增趋势，需目标服务显式开启 |
| 6 | 中间件监控 | 监控目标（492，mysql/redis/rocketmq/http 类型） | MySQL / Redis / RocketMQ / 任意 URL（Nacos、ES 等） |
| 7 | OS 主机监控 | 监控目标（492，os 类型） | monitor 所在主机 CPU/内存/磁盘/网卡/uptime |
| 8 | Redis 缓存监控 | 缓存监控（494） | 键树浏览、值查看、删键（按权限显隐） |
| 9 | Redis 慢命令抓取 | 目标详情（492 内） | 排查工具：限时抓取 SLOWLOG，定位慢 key/命令 |
| 10 | 阈值告警 | 告警中心（493） | 按目标规则评估，firing → resolved 状态机 |
| 11 | 告警通知 | 告警中心（493，通知设置） | 站内信 + Webhook 群机器人，界面可配 |

**监控闭环**：

```
接入目标（8 类探针，差异化表单）
  → 调度器每 10s 轮询 → 到期目标（默认 30s 间隔）并发探测
  → 采样落 mon_record（保留 7 天，每日 04:30 清理）→ 最近状态快照回写目标
  → 总览网格 / 目标详情趋势（1h/24h/7d）
  → 命中告警规则 → 告警（firing）→ 站内信/Webhook 通知 → 恢复（resolved）再通知
  → Redis 目标可下钻：缓存键树浏览 / 慢命令抓取
```

## 二、监控目标管理

8 类监控对象统一一张目标表，差异化表单按类型呈现；凭据查询统一脱敏（`******`）。

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| Java 微服务（service） | GET `{url}/actuator/health`，UP/DOWN + 响应延迟 | 平台运维管理员 |
| 任意 URL（http） | GET 目标地址，JSON `status` 字段语义识别（green/yellow/red，Nacos/ES 集群健康即配此类型） | 平台运维管理员 |
| JVM（jvm） | GET `{url}/actuator/metrics/*`：堆已用/上限/使用率、非堆、线程数、GC 次数与耗时（每间隔增量）、进程 CPU | 平台运维管理员 |
| 慢SQL（slowsql） | GET `{url}/actuator/slowsql`：采集开关状态、累计/每间隔新增、最近慢 SQL 列表（时间/耗时/Mapper/SQL） | 平台运维管理员 |
| MySQL（mysql） | JDBC 单连接 `SHOW GLOBAL STATUS/VARIABLES`：存活、延迟、连接数、QPS（Questions 差值） | 平台运维管理员 |
| Redis（redis） | Lettuce 直连 `INFO`：存活、延迟、内存用量、连接数、命中率、OPS、慢命令（仅抓取期间） | 平台运维管理员 |
| RocketMQ（rocketmq） | `DefaultMQAdminExt` 连 namesrv：namesrv 存活、broker/集群数 | 平台运维管理员 |
| 操作系统（os） | OSHI 本机采集（仅 monitor 所在主机）：CPU、内存、各挂载点磁盘、网卡速率、uptime；目标由调度首轮自动创建，无需手工接入 | 平台运维管理员 |
| 目标启停 | 停用的目标不参与调度；启停开关按「目标编辑」权限显隐 | 平台运维管理员 |
| 立即检测 | 不等采集间隔，手动触发一次探测并回写状态（部署后验证链路用） | 平台运维管理员 |
| 采集间隔 | 按目标可配（秒），新目标默认 30s；中间件类可放宽到 60s | 平台运维管理员 |
| 告警规则 | 按目标 JSON 规则（见第八节），表单逐项填写、0=不启用 | 平台运维管理员 |

## 三、指标采集与趋势

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| 周期采样 | 调度器每 10s 轮询，启用中且到达采集间隔的目标提交线程池（并行度 4）并发探测 | —（后台） |
| 采样留存 | 采样落 `mon_record`（指标 JSON），保留 7 天（可配），每日 04:30 清理 | —（后台） |
| 状态快照 | 最近状态/耗时/时间回写目标行，总览与列表直读 | —（后台） |
| 趋势图 | 目标详情 echarts 趋势，近 1 小时 / 24 小时 / 7 天三档切换 | 监控查看角色 |
| 差值口径 | GC 次数/耗时、慢SQL 新增、MySQL QPS 均为相邻两次采样差值——目标服务或 monitor 重启后首轮无增量属正常 | 监控查看角色 |

## 四、中间件监控

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| MySQL | 连接数、QPS；告警规则 `mysqlMaxThreads`（连接数上限） | 平台运维管理员 |
| Redis | 内存用量、命中率、OPS、连接数；告警规则 `redisMemPercent`；凭据与「缓存监控」同源 | 平台运维管理员 |
| RocketMQ | namesrv 存活、broker/集群数（rocketmq-tools 与服务端 5.3.1 对齐，外层硬超时兜底） | 平台运维管理员 |
| 任意 URL | Nacos 控制台、Elasticsearch `_cluster/health` 等任意 HTTP 端点存活与延迟 | 平台运维管理员 |

## 五、JVM 与慢SQL 监控（启用前提）

两类目标零侵入但依赖目标服务的 actuator 端点暴露，**种子目标默认停用**，确认前提满足后再启用（见 [05-配置手册](05-配置手册-零基础版.md) 第四节）：

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| JVM 指标 | 目标服务 exposure 需含 `metrics`（仅配置）；堆使用率告警 `jvmHeapPercent` | 平台运维管理员 |
| 慢SQL 采集开关状态 | 目标显示 up 且「慢SQL采集=否」= 目标服务未开启开关，不会误报 0 条 | 平台运维管理员 |
| 慢SQL 列表 | 目标服务需开启框架慢 SQL 开关 + exposure 含 `slowsql`；明细存最近 5 条（SQL 截断 300 字符，仅静态文本与 `?` 占位符，无参数值），全量环形缓存在目标服务内存 | 平台运维管理员 |
| 慢SQL 告警 | 规则 `slowSqlCount`（每间隔新增达到 N 条）；网关（WebFlux 无数据源）不支持慢SQL 目标 | 平台运维管理员 |

## 七、Redis 缓存监控与慢命令抓取

在 redis 类型目标之上提供缓存内容的查看与运维能力（Lettuce 按请求直连，凭据取自目标配置）：

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| 实例概览 | INFO 概览：版本/内存/命中率/连接数/OPS/键量 + 各 db keyspace | 缓存运维角色 |
| 键树浏览 | SCAN + 模式匹配取键名全集，按冒号分层构建 RDM 风格树（文件夹带子孙键计数、树内再筛选）；单次 SCAN 收集上限 5000，超出置 capped 提示缩小匹配模式 | 缓存运维角色 |
| 键值查看 | string 自动识别 JSON 美化/二进制标记（截断 64K 字符）；hash/list/set/zset/stream 预览前 200 条（含编码与内存占用） | 缓存运维角色 |
| 删键 | 二次确认、删除数量返回提示；按钮按 `monitor:cache:delete` 权限显隐，无权限者见纯只读视图 | 缓存运维角色 |
| 慢命令抓取 | 目标详情页开关（无 DDL，存 mon_setting）：按时长（30 分钟/1 小时/2 小时）或起止时间窗，到期自动停，界面实时显示「抓取中」；抓取期间每轮采集多执行两条只读命令 `SLOWLOG GET/LEN`（条数上限可配，默认 10），非抓取时零额外开销；「最近慢命令」表格（时间/耗时/命令/Key/参数） | 平台运维管理员 |
| 慢命令告警 | 规则 `redisSlowCmdCount` 仅在抓取开启期间评估，关闭即静默，防忘记关开关误告警 | 平台运维管理员 |

## 八、阈值告警

按目标告警规则评估，**触发即通知、持续触发不重复轰炸（可配周期重发）、恢复也通知**。

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| 规则项 | `down`（宕机）/ `latencyMs`（响应耗时）/ `cpuPercent` / `memPercent` / `diskPercent`（OS）/ `redisMemPercent` / `mysqlMaxThreads` / `jvmHeapPercent` / `slowSqlCount` / `redisSlowCmdCount` | 平台运维管理员 |
| 告警状态机 | firing（触发中）→ resolved（已恢复）；记录首次/最近触发时间与恢复时间 | —（自动） |
| 告警级别 | warn（警告）/ error（严重） | —（自动） |
| 手动处理 | 告警中心行内「处理」：转已恢复并发送恢复通知（二次确认），适合已人工修复但等不及自动恢复的场景 | 告警处理角色 |
| 通知留痕 | 每条告警记录通知结果 JSON（inbox/webhook 各通道成功/失败） | 告警处理角色 |

## 九、告警通知（界面可配，存 mon_setting 表）

| --- | --- | --- |

| 重复通知间隔 | 持续触发时的周期重发分钟数（0=不重复，防轰炸默认） | 通知设置维护角色 |
| 默认值 | 种子默认行：站内信 → admin（id=1），Webhook 关闭 | —（种子） |

## 十一、在线 / 离线两形态（`mse.monitor.offline`，缺省 false）

| 维度 | 在线（缺省 false） | 离线（true，租户离线私有部署形态） |
| --- | --- | --- |
| 运营主体 | **平台运营**——平台端查看/维护平台目标全家桶（网关/基座服务/中间件），租户端菜单虽双端存在但人为控制不授权（默认套餐不含监控页面） | **租户自管**——租户授权监控页面后在租户端维护本地监控 |
| 数据世界 | 按目标归属分库：平台会话（tenant_id=0）全部 mon_* 语句落**平台库**，租户会话行级过滤本租户库；无上下文（调度线程）默认平台语义 | 整体退化为「**本地单一监控世界**」：mon_* 采集/查询/告警/通知全部直连**本地缺省库**（不再路由平台库、不按会话租户过滤），本机 OS 目标同落本地；平台/租户会话看到同一个本地世界 |
| 平台库副本 | 分库形态必需（`monitor_platform.sql` 建平台库 mon_* 表 + 平台种子） | 同样生效（监控弃用平台库，副本无害） |
| 配置位置 | Nacos `mse-monitor.yaml` 与本地 yaml 均可配；单体/微服务两形态通用 | 同左；仅离线部署语义下使用，在线共享部署保持 false |

补充边界：monitor-boot 微服务形态未注册 platform 数据源，平台会话回落业务主库（业务库种子仍在服役）；分库形态下调度器主库扫描在平台库已注册时排除 tenant_id=0 残留行，避免采集回写跨库漂移。
