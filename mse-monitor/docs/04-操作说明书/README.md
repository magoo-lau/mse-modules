# 04 操作说明书 —— 总览与使用指南

> MSE 监控中心**分角色操作说明书**总览。每本手册面向一个岗位，讲清「这个岗位能做什么、在哪个页面做、按什么顺序做」。
> 功能全景见 [01-功能规划](../01-功能规划.md)；角色授权设计依据见 [03-角色规划](../03-角色规划.md)。手册描述以当前系统实际界面为准。

## 一、手册索引（按岗位领取）

| 手册 | 使用者 | 数据范围 | 一句话定位 |
| --- | --- | --- | --- |
| [01-平台运维管理员](01-平台运维管理员.md) | 平台运维岗（平台端） | 平台世界（tenant_id=0：网关/基座服务/中间件） | 监控目标接入、指标查看、告警与通知配置 |
| [02-租户管理员](02-租户管理员.md) | 租户管理员（租户端） | 本租户世界 / 离线本地世界 | 离线私有部署形态的本地监控自管 |

> 角色分配：平台端由平台管理员、租户端由租户管理员在基座「角色管理」按 [03-角色规划](../03-角色规划.md) 的建议角色授予。本工程未内置角色种子，角色需按需创建。租户端菜单还受「套餐管理」勾选约束（默认不勾选）。

## 二、进入系统

1. 用平台账号（平台端）或企业账号（租户端）登录**基座门户**。
2. 左侧导航找到「**监控中心**」分组目录，展开即见四个页面：监控总览、监控目标、告警中心、缓存监控。菜单按你的角色授权显示——看不到某个菜单表示该角色未授权，租户端还可能是套餐未包含。
3. 界面为微前端嵌入运行：导航、登录态、深浅色主题均由基座统一管理，监控页面内不再单独登录。
4. **双端口径**：平台端看到的是平台自身的监控对象（网关、基座微服务、中间件、monitor 所在主机 OS）；租户端看到的是本租户自建的监控对象；**离线私有部署**（实施将 `mse.monitor.offline` 设为 true）时两端看到的是同一个本地监控世界。

## 三、监控全景

```
监控目标（8 类：服务/HTTP/JVM/慢SQL/MySQL/Redis/RocketMQ/OS 本机）
  → 系统每 10 秒轮询、按目标间隔（默认 30 秒）自动探测
  → 监控总览（统计卡 + 状态网格）→ 目标详情（当前指标 + 趋势图 近1h/24h/7d）
  → 命中告警规则 → 告警中心（触发中 → 已恢复）→ 通知（站内信 / 钉钉·企微·飞书机器人）
  → Redis 目标下钻：缓存监控（键树浏览/删键）· 慢命令抓取（排查慢 key）
```

## 四、通用操作（所有页面一致）

### 4.1 列表与筛选

- 筛选区在列表上方：文本框输入后按**回车**或点「查询」触发；下拉筛选**选中即自动刷新**；点清除图标恢复全部。
- 列表分页显示；趋势图提供近 1 小时 / 24 小时 / 7 天三档切换。

### 4.2 状态点与颜色

- 目标状态三色：绿点=正常（up）、红点=异常（down）、灰点=未知（unknown，尚未采集到首轮或刚启用的目标）。
- 告警状态：「触发中」（红）/「已恢复」（绿）；告警级别：「警告」warn /「严重」error。

### 4.3 弹窗与确认

- 所有「删除」「处理」「删键」类操作都有二次确认弹窗，按提示确认才执行。
- 通知设置、慢命令抓取等配置弹窗保存即生效，无需重启。

### 4.4 外观

深浅色模式与主题色跟随基座门户设置（门户右上角切换），监控页面自动跟随，无需单独设置。

## 五、状态字典速查（界面标签的准确含义）

| 业务对象 | 状态枚举 |
| --- | --- |
| 监控目标 | 正常（up）/ 异常（down）/ 未知（unknown）；启停：启用 / 停用（停用不参与采集） |
| 告警 | 触发中（firing）→ 已恢复（resolved）；级别：警告 / 严重 |
| 慢SQL 采集 | 「慢SQL采集=否」表示目标服务未开启慢SQL 开关（非故障）；=是 时展示最近慢语句 |
| 慢命令抓取 | 抓取中（显示自动停止时间）/ 已关闭；仅抓取期间产生慢命令数据，关闭即消失 |
| 缓存键树 | 文件夹=按冒号分层的前缀（带子孙键计数）；叶子=具体键；「已达扫描上限」提示=匹配模式过宽需缩小 |
| 通知结果 | 站内信 / Webhook 各通道：发送成功 / 失败原因 |

## 六、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 左侧看不到「监控中心」菜单 | 平台端：角色未授权；租户端：套餐未勾选（默认不勾选）或角色未授权。联系平台/租户管理员。 |
| 看不到某个按钮 | 按钮按权限显隐（如无「目标编辑」权限不显示新增/启停；无删键权限缓存页为纯只读）。找管理员补授权。 |
| 目标一直「未知」 | 目标刚启用还未到首个采集周期，或目标地址不可达。可点行内「检测」立即验证。 |
| 目标显示「异常」但服务明明在跑 | 检查目标地址/端口是否填对（容器部署填容器网络地址而非 localhost）；目标服务开了 actuator 鉴权而监控侧令牌未对齐也会表现为拉取失败。 |
| JVM/慢SQL 目标启用后无数据 | 目标服务未暴露对应端点（metrics/slowsql），或慢SQL 开关未在目标服务开启——由实施按 [05-配置手册](../05-配置手册-零基础版.md) 第四节处理后启用。 |
| 重启后首轮没有 GC/QPS/慢SQL 增量 | 差值口径：重启后首轮无增量属正常，下个周期恢复。 |
| 告警没收到通知 | 「告警中心 → 通知设置」未启用或收件人/机器人地址不对；用「发送测试」验证通道。 |
| 告警一直重复轰炸 | 「重复通知间隔」为 0 表示持续触发不重复通知；若配了间隔属正常周期重发，可调大或归零。 |
| 缓存键树提示已达扫描上限 | 匹配模式过宽（如 `*`），缩小前缀（如 `mse:session:*`）再查。 |
| 缓存页看不到「删除该键」按钮 | 无删键权限，纯只读视图属正常设计。 |
| 慢命令表格是空的 | 慢命令抓取未开启或刚关闭——数据只在抓取期间产生，重新开启抓取再观察。 |
| 新建租户库期间日志有 Unknown database 提示 | 初始化窗口期的正常中间态，初始化完成后自动纳入监控，无需处理。 |
