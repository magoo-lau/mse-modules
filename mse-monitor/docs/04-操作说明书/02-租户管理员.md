# 02 租户管理员操作手册

> 使用者：租户管理员（租户端）｜数据范围：本租户世界（在线形态被授权时）或离线本地世界（私有部署形态）｜菜单：「监控中心」全部页面。
> 定位：**离线私有部署形态下的本地监控自管**——在租户端维护本环境的监控目标、告警与通知；在线共享形态下监控默认由平台运营，租户端不可见（见第五节）。

## 一、适用场景与前提

| 场景 | 你能做什么 | 前提 |
| --- | --- | --- |
| **离线私有部署**（实施把监控设为离线模式，本册主线） | 在租户端全面维护本地监控：目标接入/启停/告警/通知/缓存运维 | 平台端「套餐管理」勾选「监控中心」+ 角色授权 |
| 在线共享形态 | 默认**看不到**监控中心（监控由平台运营）；若平台为你的租户开通，可看**本租户自建目标**的世界 | 平台端套餐勾选 + 角色授权 |

> 离线模式下，平台端与租户端看到的是**同一个本地监控世界**：你维护的目标就是本环境的全部监控。

## 二、进入系统与首次巡视

1. 登录基座门户，左侧导航展开「**监控中心**」。
2. 先看 **监控总览**：统计卡（目标总数/正常/异常/未知/已停用/告警中）+ 目标状态网格 + 最近告警。
3. 再看 **监控目标**：环境就绪后系统已自动登记「本机操作系统」目标（无需手工接入）；本环境的 MySQL、Redis、各应用服务由实施预置或由你按下节接入。

## 三、本地监控目标维护

> 路径：监控中心 → **监控目标**。操作方法与平台端一致（差异化表单、启停开关、行内「检测」），这里只列租户本地环境的要点：

1. **接入本环境服务**：逐个为本地部署的应用服务建 service 类型目标（地址 `http://本机或内网IP:端口`），建完点「检测」验证变绿。
2. **接入本地中间件**：MySQL（主机+端口+账号密码，建议只读账号）、Redis（主机+端口+密码）、消息队列等按类型填写。
3. **本机操作系统**：系统自动创建，CPU/内存/磁盘/网卡一站式采集，确认处于「启用」即可。
4. **为关键目标配告警规则**：宕机 + 响应耗时必配；数据库/缓存加资源阈值（经验值见 [01-平台运维管理员](01-平台运维管理员.md) 第四节）。
5. **停用不用的目标**：停用目标不参与采集、不产生误报；地址变更走「编辑」。

## 四、告警与通知（本地环境必须配一次）

> 路径：监控中心 → **告警中心** → 「通知设置」。

1. **站内消息**：收件人从**本租户用户**中检索选择（建议选管理员本人 + 值班同事）。
2. **Webhook 群机器人**：有企业群（钉钉/企微/飞书）时强烈建议开启——离线环境往往没人盯着页面，群机器人是最快的通知通道；填完「发送测试」验证。
3. **重复通知间隔**：默认 0（持续触发不重复轰炸）；夜间值守可设 30-60 分钟周期重发。
4. 告警产生后：在告警中心按状态/关键字筛查；已人工修复的告警点「处理」转已恢复。

## 五、在线/离线形态差异速查

| 事项 | 在线共享形态 | 离线私有部署形态 |
| --- | --- | --- |
| 菜单可见性 | 默认不可见（平台运营监控） | 套餐勾选后可见 |
| 数据范围 | 本租户自建目标 | 本地全部监控（含平台预置目标与本机 OS） |
| 通知收件人 | 本租户用户 | 本租户用户（本地环境） |
| 缓存监控 | 本租户目标中的 Redis | 本地 Redis |
| 由谁运维 | 平台运维管理员 | **你自己（本册）** |

形态由实施部署时确定（配置开关），日常使用无需关心切换。

## 六、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 登录后没有「监控中心」菜单 | 套餐未勾选（默认不勾选，找平台管理员开通）或你的角色未授权菜单。 |
| 新建目标一直「未知」 | 地址不可达或刚启用未到首个采集周期；点「检测」验证，检查地址是否应填内网/容器地址。 |
| 收不到告警 | 通知设置未启用或收件人未选；先「发送测试」。离线环境注意服务器到群机器人的外网连通性。 |
| 缓存页没有删键按钮 | 你的角色未授予删键权限（只读视图属正常设计）；确需删键找管理员，或由有权限的同事操作。 |
| 慢命令表格为空 | 慢命令抓取开关未开启；到目标详情页开启抓取再观察，排查完记得关闭。 |
| 服务明明在跑但显示异常 | 目标服务开启了接口鉴权而监控令牌未对齐，或地址/端口填错——联系实施核对（见 [05-配置手册](../05-配置手册-零基础版.md) 第四节）。 |
| 告警「处理」后还会再触发吗 | 会——「处理」只是把当前这条转为已恢复；若根因未消除、下轮采集仍命中规则，会产生新告警。请先排除根因。 |
