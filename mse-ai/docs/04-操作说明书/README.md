# 04 操作说明书 —— 总览与使用指南

> MSE-AI 智能体平台**分角色操作说明书**总览。每本手册面向一个使用岗位，讲清「这个岗位能做什么、在哪个页面做、按什么顺序做」。
> 功能全景见 [01-功能规划](../01-功能规划.md)；角色授权设计依据见 [03-角色规划](../03-角色规划.md)。手册描述以当前系统实际界面为准，不涉及任何代码与 SQL。

## 一、手册索引（按岗位领取）

| 手册 | 角色 | 数据范围 | 一句话定位 |
| --- | --- | --- | --- |
| [01-平台管理员](01-平台管理员.md) | 平台账号（平台世界） | 平台世界 + 全局用量 | 出厂模型模板维护、平台公共智能体、API Key 归属签发、全局用量 |
| [02-租户AI管理员](02-租户AI管理员.md) | ai_admin（建议角色） | 本租户 | 模型通道、智能体编排（含画布）、知识库、工具中心、开放能力 |
| [03-普通用户](03-普通用户.md) | ai_user（建议角色） | 本人会话 | 对话工作台问答、智能体选择、查看个人用量 |

> 角色分配：由租户管理员在基座「组织管理 → 角色管理」创建角色并授权（本工程无预置角色，建议编码 `ai_admin` / `ai_builder` / `ai_user`，明细见 03 号规划文档）。一个员工可兼多角色，权限取并集；所有人可见的菜单还受租户「套餐」勾选的上界约束。本工程另有「AI 应用建设者」（ai_builder）中间角色：能编排智能体 / 维护知识库但不接触模型 Key 与 API Key——其操作覆盖在 02 号手册内，涉模型 / 开放能力的步骤跳过即可。

## 二、进入系统

1. 用企业账号登录**基座门户**（浏览器访问门户地址）。
2. 登录后在左侧导航找到「**AI 服务**」分组目录，展开即见全部页面：对话工作台、智能体管理、知识库、用量统计、模型管理、工具中心、开放能力。菜单按你的角色授权显示——看不到某个菜单表示该角色未授权或套餐未包含。
3. 界面为微前端嵌入运行：导航、登录态、深浅色主题均由基座统一管理，AI 页面内不再单独登录。
4. 平台管理员用**平台账号**登录平台门户后访问同一组页面——看到的是「平台世界」的数据（出厂模板与全局用量），与各租户数据互相隔离。

## 三、系统业务全景

```
模型管理：配好大模型通道（对话 / 向量 / 重排三类，测通才算数）
   ↓
知识库（可选）：建库 → 传文档 → 自动解析切片向量化 → 检索测试满意
   ↓
工具中心：核对可用工具（系统自动登记 + 按需登记外部 HTTP/Dify/MCP 工具）
   ↓
智能体管理：新建智能体 → 绑模型 + 写提示词 + 勾工具 + 勾知识库
   →（可选）画布编排：拖节点搭工作流 → 试运行调试 → 保存草稿
   → 发布（只有"已发布"的智能体才会出现在对话页与对外通道）
   ↓
消费：对话工作台流式问答 ／ 业务系统内嵌 AI 功能 ／ 第三方系统开放 API 调用
   ↓
度量：用量统计看消耗，工具中心看每次调用的审计日志，智能体列表看运行历史
```

## 四、通用操作（所有页面一致）

### 4.1 列表与筛选

- 筛选区在列表上方：文本框输入后按**回车**或点「查询」触发；下拉筛选**选中即自动刷新**。
- 列表分页显示；删除、启停等危险操作均有二次确认。

### 4.2 对话通用说明

- 对话回复为**逐字流式**输出；等待中可点「**停止**」随时中断（画布编排的智能体会在当前节点结束后尽快停下，半截回答不记入会话记忆）。
- 智能体调用工具时，消息区内实时显示「正在调用 ×× 工具」；返回的是数据表时自动展示「表格 / 图表」卡片，可切换图形样式。
- 绑定了知识库的回答，下方附**引用来源**（文件名 / 命中得分 / 摘要），点开可核对原文出处。
- **AI 红线**：AI 输出仅供参考，涉及业务操作（审批、下单、发布等）一律人工确认；智能体只能查数据、不能直接改业务数据。

### 4.3 外观

深浅色模式与主题色跟随基座门户设置（门户右上角切换），AI 页面自动跟随，无需单独设置。

## 五、状态字典速查（界面标签的准确含义）

| 业务对象 | 状态枚举 |
| --- | --- |
| 模型 | 启用 / 停用；测试结果：成功 / 失败（失败原因留档）；向量模型可标「默认」 |
| 智能体 | 已发布 / 已下线（只有已发布进入对话页、业务系统与开放 API）；编排模式：简单配置 / 画布编排 |
| 画布 | 草稿 / 运行版（发布时把草稿拷贝为运行版，编辑草稿不影响线上） |
| 运行历史 | success 成功 / failed 失败 / cancelled 已取消（通道：对话 / 试运行 / 业务调用 / 开放接口） |
| 知识库文档 | 待处理 → 处理中 → 完成 / 失败（失败可重试、可重新解析；改切片配置后需重建索引） |
| 工具 | 启用 / 停用；来源：内置 / 本地 / RPC 自动登记（不可手工新增）、HTTP / Dify 手工登记、MCP |
| API Key | 启用 / 停用（Key 明文只在签发时显示一次） |
| MCP Server | 启用 / 停用（登记后可连通性测试） |

## 六、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 左侧看不到「AI 服务」菜单 | 该角色未授权此菜单，或租户套餐未勾选。联系租户管理员在「角色管理 / 套餐管理」检查。 |
| 对话报「模型不可用」或一直转圈 | 智能体绑定的模型没配好或余额 / Key 失效。联系 AI 管理员在「模型管理」点「测试」核实。 |
| 对话页看不到某个智能体 | 只有「已发布」的智能体才出现在下拉里；请 AI 管理员到「智能体管理」发布。 |
| 回答不带引用来源 | 该智能体未绑定知识库，或知识库检索未命中。建设者可在智能体编辑里勾选知识库。 |
| 文档一直「处理中」 | 解析是后台异步的，大文件需等待；服务重启后历史「待处理 / 处理中」文档不会自动恢复，需手动「重新解析」。 |
| 工具列表里有行删不掉又自动出现 | 系统自动登记的工具（内置 / 本地 / RPC）以提供方为权威，删除后重启会自动回来——不需要删，用「停用」即可。 |
| 改了智能体提示词但对话没变化 | 简单模式保存即生效；**画布编排**模式需重新「发布」把草稿拷贝为运行版。 |
| API Key 丢了 | Key 明文只在签发弹窗显示一次，丢了只能停用旧 Key 重新签发。 |
| 看得到「用量统计」但没有数据 | 只显示当前租户的用量；刚开通还没有对话记录时为空。全局用量在另一张「用量统计（全局）」页。 |

## 七、阅读建议

- 新岗位上手：先读本手册第二、三节建立全局认识，再读对应角色手册的「典型流程」。
- 遇到具体按钮 / 字段疑问：查角色手册的分步操作，按钮文字与界面一致，可直接对照。
- 状态流转拿不准：查第五节状态字典。
