# 03 普通用户操作手册

> 角色：`ai_user`（建议角色，AI 普通用户）｜数据范围：本人会话｜菜单：对话工作台（用量统计可选）。
> 定位：AI 能力的**使用者**——在对话工作台选智能体问答、查资料、看分析。不需要配任何东西；看不到「模型管理 / 智能体管理」等菜单属正常设计。

## 一、职责与页面清单

| 职责 | 页面 |
| --- | --- |
| 与 AI 智能体流式对话、管理自己的历史会话 | 对话工作台 |

## 二、对话工作台

> 路径：AI 服务 → **对话工作台**。左侧会话列表，右侧消息窗。

### 2.1 开聊

1. 顶部下拉选择智能体（能看到的是管理员**已发布**的，如「通用助手」「数据智能分析师」或本企业自建的助手）；切换智能体后新开一轮即可生效。
2. 底部输入框输入问题，回车或点发送；回答**逐字输出**，不用等整段。
3. 新建会话：点「新建会话」开始互不干扰的一轮话题；左侧会话可**重命名 / 删除**，历史会话点开继续聊（AI 记得本会话上下文）。

### 2.2 读懂回答里的附加信息

- **「正在调用 ××」**：智能体在调用工具查数据（如查业务系统数据、查知识库），属正常过程，稍候。
- **表格 / 图表卡片**：返回的是数据集时自动展示，可在表格与图表（柱 / 条 / 折 / 饼）间切换，刷新或回放会话时仍在。
- **引用来源**：绑定知识库的回答下方列出依据（文件名 / 得分 / 摘要）——重要结论点开核对原文，**不要只信 AI 转述**。
- **「执行过程」时间线**：工作流类智能体的回答内嵌各步骤轨迹，可展开看它怎么得出的结论。

### 2.3 停止与纠错

- 回答跑偏或太长：点「**停止**」立即中断，重新组织问题再问。
- AI 答错 / 编造：换个问法、补充背景，或换绑知识库的智能体；涉及业务操作（审批、下单、删改数据）**一律以业务系统为准**，AI 回答仅供参考。

## 三、知识问答的推荐问法

- 问「有出处的问题」：把背景说全（时间段、部门、产品、单号），如「2026 年 9 月华东区的报销单平均审批时长是多少？」。
- 问文档内容：直接像问同事一样问，如「出差补贴标准是什么？」——回答会附制度文件名，点开核对条款。
- 要数据时指定口径：「按月统计」「只看已完成」「TOP 10」，数据类智能体会生成查询并回表。
- 一轮只问一件事；复杂问题拆步问，或让 AI「先列提纲再逐项展开」。

## 五、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 下拉里找不到某个智能体 | 它未发布或被管理员下线了；联系租户 AI 管理员确认。 |
| 提问后报「模型不可用」 | 模型通道临时故障 / Key 额度问题，稍后重试；持续报错联系 AI 管理员。 |
| 回答很慢 | 生成长文 / 调用了外部工具都需时间；等不及点「停止」再问得具体些。 |
| 回答没有引用来源 | 该智能体没绑知识库，或库里没有相关资料；向管理员反馈补充文档。 |
| 历史会话找不到了 | 会话删除不可恢复；重要结论请及时复制留存。 |
| 图表样式不合适 | 点卡片上的图表类型切换（柱状 / 条形 / 折线 / 饼图）。 |
| AI 说的和系统里对不上 | 以业务系统数据为准，并把出入反馈给管理员（工具取数口径可能需修正）。 |
| 看不到「AI 服务」菜单 | 你的角色未授权或套餐未包含；联系租户管理员。 |
