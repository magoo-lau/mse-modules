# 02 租户 AI 管理员操作手册

> 角色：`ai_admin`（建议角色，AI 平台管理员）｜数据范围：本租户全部 AI 资源｜菜单：「AI 服务」分组全部页面。
> 定位：本租户 AI 能力的**建设与治理者**——配模型通道、编排智能体（含画布工作流）、维护知识库、管理工具与开放能力。不负责基座侧的用户 / 角色 / 套餐管理（那是租户管理员的事）。
> 开通即得：租户创建时系统已自动播种 6 个出厂智能体副本（含「通用助手」）与模型副本——**开箱即可对话**，本手册讲的是怎么配出你自己的专属能力。

## 一、职责与页面清单

| 职责 | 页面 |
| --- | --- |
| 配置本租户自己的大模型 Key 与通道（对话 / 向量 / 重排） | 模型管理 |
| 编排智能体、画布工作流、发布下线、看运行历史 | 智能体管理 |
| 建知识库、传文档、调检索、管分块 | 知识库 |
| 登记外部工具（HTTP / Dify / MCP）、启停与测试工具 | 工具中心 |
| 签发开放 API 密钥给第三方系统、登记 MCP Server | 开放能力 |
| 查看本租户用量 | 用量统计 |

## 二、模型管理（本租户的 Key 自己管）

> 路径：AI 服务 → **模型管理**。典型场景：租户配自己的 DeepSeek / 智谱 Key 计费。

1. 「新增模型」→ 选模型类型 → 选供应商（端点自动带出）→ 填 API Key → 「测试」通过后保存。
2. **需要知识库（RAG）时**，另建一行「向量模型」（DeepSeek 无向量端点，可配智谱 `embedding-3` 或本地 Ollama），配好后点「**设默认**」；有精排需求再建「重排模型」行。
3. 给重要对话模型配「**备用模型**」，上游抖动 / 限流时自动切换。
4. 开通时播种的模型副本可直接编辑：改成本租户自己的 Key 即可；不用的行停用或删除。

> 提示：智能体不绑定模型时走自动回退（服务默认模型，或本世界首个可用模型）——正式使用建议逐个显式绑定，避免「换个环境行为就变」。

## 三、智能体管理（编排你的专属 AI 应用）

> 路径：AI 服务 → **智能体管理**。列表即本租户全部智能体（含出厂副本，均可编辑 / 发布 / 删除）。

### 3.1 简单模式（提示词 + 工具 + 知识库）

1. 点「新增智能体」：编码（英文唯一，业务系统按它引用）、名称、头像、描述、开场白。
2. 编辑页四件事：
   - **绑定模型**：从本租户模型行选（只列对话模型）；调温度控制回答随机性；
   - **系统提示词**：写清角色 / 规则 / 输出格式，支持 `{{变量}}` 占位；
   - **绑定工具**：多选（内置 / 业务系统工具 / HTTP / Dify / MCP 都在下拉）；
   - **绑定知识库**：多选启用 RAG，回答自动附引用来源。
3. 点「**发布**」。只有已发布智能体才会出现在对话工作台与业务系统的选择器里；随时「下线」。

### 3.2 画布编排（复杂流程才用）

对标主流 AI 工作流产品，把「分类 → 检索 → 生成」这类多步流程画出来：

1. 智能体编辑里把编排模式切为「画布编排」，或新建时选模板（内置「**数据分析助手**」：抽参数 → 查数据 → 分析 → 回复）。
2. 进入画布编辑器：左侧节点面板拖入节点（大模型 / 知识检索 / 工具 / 数据查询 / 条件分支 / 问题分类 / 参数提取 / 代码执行 / HTTP 请求 / 模板转换 / 变量赋值 / 变量聚合 / 迭代 / 回复 / 结束），连线成流程。
3. 节点连线处引用上游输出：点击节点卡片上的变量即可复制 `{{引用}}`，在下游节点属性面板「在光标处插入」；顶部「**全局参数**」可定义画布级参数。
4. 底部「**试运行**」：填入参 → 看节点时间线与流式回答，调试满意后「保存草稿」。
5. 点「**发布**」把草稿拷贝为运行版——**之后改草稿不影响线上**，改完再发布才生效。
6. 支持导入导出：自有格式 YAML 备份复用，也支持**导入 Dify 的 DSL**（不可自动映射的项会给警告清单，人工补配）。

### 3.3 运行历史与排障

- 列表「**运行**」弹窗：每次执行的结果（成功 / 失败 / 取消）、耗时、节点轨迹时间线回放——排障第一步看这里。
- 对话里显示「正在调用某工具」卡住或报错：去工具中心看该工具的「调用日志」（入参 / 出参 / 失败原因）。

## 四、知识库（让 AI 答你自己的资料）

> 路径：AI 服务 → **知识库**。前置：管理员已在模型管理配好向量模型并设默认（或建库时显式绑定）；向量库服务已部署（未部署时文档只存库不向量化，无法检索）。

1. 「新建知识库」：名称、描述、**切片方法**（通用 / 问答对 / 表格 / 书籍 / 整篇）、切片大小与重叠、检索条数与相似度阈值；可选开启「**索引增强**」（解析时自动为每块生成关键词与候选问题，问句式提问召回更好）。
2. 进入知识库 → 「**上传文档**」：上传即返回，后台异步解析（状态：待处理 / 处理中 / 完成 / 失败），失败可重试。
3. 解析完成后先做「**检索测试**」：输入用户可能问的句子，看命中片段与得分——不满意再调切片配置，改完点「**重建索引**」对存量文档生效。
4. 「分块」页签：可手工新增 / 编辑 / 删除分块（保存即重新向量化），用于修正个别召回错误的片段。
5. 把知识库绑定到智能体（见第三节），回答即带引用来源。

## 五、工具中心（接外部能力）

> 路径：AI 服务 → **工具中心**。系统工具（内置 + 业务系统自动登记的）开箱即在列表，**用启停控制，不要删除**（删了会自动回来）。

- **登记 HTTP 工具**：「登记工具」→ 来源选 HTTP → 填地址、请求方法、请求头（可放鉴权）、Body 模板；功能说明与每个参数说明**必填**（这是模型判断何时调用的唯一依据）。
- **登记 Dify 应用**：来源选 Dify → 填地址与应用 API Key、应用类型（workflow / completion / chat）。
- **接 MCP**：先在「开放能力」登记 MCP Server 并测试连通，其工具自动出现在工具下拉（编码形如 `mcp:服务:工具`）。
- 每个登记完的工具都点「**测试**」验证；「调用日志」页签看历史调用审计。

## 六、开放能力（对外服务）

> 路径：AI 服务 → **开放能力**。给第三方系统（或集团内其他系统）开调用通道：

1. 「签发密钥」：App ID、归属租户（本租户）、每分钟限流、智能体白名单（从本租户已发布智能体多选）→ 保存后**当场复制** App ID 与 API Key（仅显示一次）交给对方。
2. 告知对方调用方式：开放接口地址（`/openapi/ai/chat`，请求头带 App ID 与 Key），可查已发布智能体列表接口与流式接口。
3. 漏配 / 离职 / 换供应商：立即「停用」旧 Key，重签新 Key。
4. 若集团统一走开放平台（mse-open）授权，本工程能力已自动注册进其 API 目录，凭证与授权在开放平台侧管理，无需重复签发。

## 七、用量统计（本租户）

> 路径：AI 服务 → **用量统计**。按通道（页面对话 / 业务系统调用 / 开放接口）、智能体、模型、时间查看 tokens 消耗与耗时——核对模型账单、评估各智能体使用率的第一手数据。

## 八、租户 AI 管理员注意事项

1. **顺序**：先模型（测通）→ 再知识库（检索测试满意）→ 再智能体（发布）——发布前用「试运行」或对话页自测。
2. **编码即契约**：智能体编码被业务系统的「场景映射」与开放 API 白名单引用，发布后不要轻易改编码。
3. **提示词是核心资产**：改提示词建议小步迭代 + 看运行历史对比效果；画布模式改动必须重新发布才生效。
4. **Key 安全**：模型 Key 加密存储但请勿外借；API Key 明文只出现一次，建立台账记录发给了谁。
5. **删除谨慎**：智能体 / 知识库删除影响绑定它的业务系统场景（表现为该场景 AI 功能不可用），先下线观察再删。
