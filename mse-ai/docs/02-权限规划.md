# 02 权限规划 —— 子应用注册、页面菜单与权限点

> mse-ai 的菜单与权限点**实际清单**，逐条转录自种子脚本 `ai-service/src/main/resources/db/mysql/V20261001_01_ai__ai_base.sql`（`-- mse-target: base`，starter-bridge 自动推送，幂等）。
> 功能点含义见 [01-功能规划](01-功能规划.md)，角色授权见 [03-角色规划](03-角色规划.md)。
> 已退役项（8005 / 8022 / 8023 / 菜单 469）仅在第七节留档，不在种子中——**新权限点不要复用这些 id**。

## 一、规划原则（基座 RBAC 模型）

1. **三张全局表，一条链路**：`sys_micro_app`（子应用注册）→ `sys_menu`（导航菜单）→ `sys_permission`（权限点）；授权链 `sys_user → sys_user_role → sys_role → sys_role_menu / sys_role_permission`。
2. **sys_menu.type / menu_scope**：460 为 type=1 分组目录（parent_id=0）；461-468 为 type=3 子应用页面菜单（`micro_name='ai'`、`path` 为子应用内部路由）。**全部 menu_scope=2 租户端**（平台端无 AI 菜单登记；平台世界的管理操作经同一组页面以平台登录态访问，见 03 第五节）。
3. **权限点必须挂靠页面菜单**：`sys_permission.menu_id` 指向本工程 type=3 页面菜单，参与角色授权分组与**租户套餐裁剪**（套餐勾选菜单 → 隐含圈定挂靠的权限点）；本工程无 `menu_id=NULL` 通用权限。
4. **权限码格式**：`ai:<资源>:<动作>`，动作小写动词，与仓库 `oa:form:list` / `mes:order:save` 等风格一致；表内无重复 code（数据库唯一键 `uk_code`）。
5. **前端按钮控制**：子应用内 `v-permission` 指令按权限码显隐（ai-ui/src/directives/permission.ts 已内置）。
6. **落库方式**：随 jar 的幂等版本化脚本由 starter-bridge 推送 mse-system 按账本应用（租户库车队重放至共享主库与各独立租户库）——免手工执行；已应用脚本不再修改，变更一律新增版本文件。

## 五、控制器校验口径（权限码的真实消费点）

后端 `@SaCheckPermission` 与种子一一对应（已核对 controller 层全部注解），特殊口径：

| 权限码 | 除本页 CRUD 外还把守 |
| --- | --- |
| `ai:chat:use`（8009） | `POST /ai/chat/stream`（SSE 鉴权在返回 emitter 前完成）、`/ai/chat`、会话分页/消息/改名/删除/停止；`GET /ai/agent/visible`（对话页智能体下拉） |
| `ai:agent:list`（8006） | `GET /ai/agent/run/page`、`/run/{id}`（运行历史）、`GET /ai/agent/datasource-options`（画布数据源下拉） |
| `ai:agent:save`（8007） | `POST /ai/agent/{id}/debug-run`（画布试运行）、`POST /ai/agent/{id}/dsl/import`（DSL 导入） |
| `ai:model:test`（8004） | `POST /ai/model/{id}/test`（连通性测试，向量模型回显维度） |
| `ai:kb:upload`（8012） | `POST /ai/kb/{id}/documents`（文档上传，异步解析） |
| `ai:tool:manage`（8021） | 工具登记 / 删除 / 测试 / 启停（`ai:tool:list` 仅查列表与调用日志） |

`/openapi/ai/**` 不走 Sa-Token 会话鉴权（appId + Key 自鉴权，网关白名单放行）；`/ai/platform/tenant-options`（签发密钥的租户下拉）放行 `ai:model:save` / `ai:apikey:list` / `ai:usage:platform` 任一，且**双登录态**（租户端与平台端）均可。

## 七、套餐裁剪与登记纪律

1. **租户套餐**：AI 服务页面菜单（461-468）需在平台端「套餐管理」勾选后才对租户可见；租户管理员拿到的是「套餐域内全量权限码」，裁剪对管理员同样生效。出厂智能体 / 模型 / 工具副本随租户开通自动播种，与套餐无关（副本可见性不受菜单裁剪影响，但操作入口受菜单裁剪约束）。
2. **网关白名单**：仅 `/openapi/ai/**` 一段（开放 API 自带 X-App-Id + X-Api-Key 鉴权）；其余 `/ai/**` 全部需登录态。注意 Spring list 属性整体替换，追加须全量列出。
3. **alloc-tables.md 登记**（已登记，本表为转录）：后端端口 8094、前端 dev 3800、micro_app id=7、菜单段 460-469（469 退役）、权限段 8xxx（现用 8001-8021，8005/8022/8023 退役）、网关前缀 `/ai /openapi/ai`（白名单 `/openapi/ai/**`）、ai_tool 种子 8101-8102。
4. **脚本纪律**：全部幂等写法（子应用按 name 判重、菜单 / 权限点按 id 判重）；历史挂靠修正用条件 UPDATE 幂等补挂。
