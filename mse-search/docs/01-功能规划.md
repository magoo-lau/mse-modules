# 01 功能规划 —— 功能模块与功能点

> mse-search 功能总纲。配套文档：[02-权限规划](02-权限规划.md)（页面菜单与权限点实录 id）、[03-角色规划](03-角色规划.md)（谁能用）。
> 「主要角色」为本产品的**建议角色**（工程未种角色，见 03 分册第一节）；「全员」指无需任何 search 权限即可使用基座搜索入口的普通用户。

## 一、模块总览与核心链路

| # | 模块 | 页面菜单（menu_id） | 形态 | 一句话定位 |
| --- | --- | --- | --- | --- |
| 1 | 源管理 | 源管理（481） | 租户端页面 | 可搜索源目录：启停 / 调参 / 字段配置 / 手工登记 |
| 2 | 任务中心 | 任务中心（482） | 租户端页面 | 全量重建 / 索引优化 / 立即扫描三类索引运维任务 |
| 3 | 热词统计 | 热词统计（483） | 租户端页面 | 本租户搜索热词榜与按源索引水位 |
| 4 | 搜索测试 | 搜索测试（484） | 租户端页面 | 推文档 / 查询高亮 / 三层过滤对比的验收调试台 |
| 5 | 索引管理 | 索引管理（486） | 租户端页面 | 引擎真实索引视图：浏览 / 清空 / 删除 |
| 6 | 搜索配置 | 搜索配置（487） | 租户端页面 | 租户级检索字段覆盖与新增 |
| 7 | 搜索开放 API | —（不占菜单） | 后台接口 | `/search/api/*` 供基座顶栏与首页卡片消费 |
| 8 | 增量引擎 | —（不占菜单） | 后台调度 | 定时扫描分片 + MQ 实时事件 + 闲时任务窗口 |

**核心链路**：

```
业务工程声明 SearchSourceContributor（源描述）
  → search-api 推送器推送 mse-search 源目录（幂等 upsert + 周期重推自愈）
  → SearchSourceFleetSeeder 扇出播种「平台 + 全部租户」归属上下文（新租户最迟一个推送周期目录就绪）
  → 增量通道（二选一或并存）：
      ① 定时扫描：按「租户 × 源」cron 拉取（update_time 水位 + bizId 散列分片，游标断点续扫）
      ② MQ 事件：业务写操作发 doc_upsert / doc_delete（topic mse-search-index，实时）
  → 建索引：每租户 × 每源一个索引 {mse-search}-{sourceCode}-{tenantId}，字段配置驱动 mapping
  → 用户搜索：基座顶栏 / 首页卡片 → POST /search/api/query
      → 三层权限过滤（租户隔离 → 来源可见性 → 个人数据范围）→ 高亮结果
  → 点击结果按 jumpUrl 模板跳转业务子应用详情页
```

## 二、源管理（可搜索源目录）

每租户一份目录：业务自注册的源由播种器扇出到本租户，管理端亦可手工登记（调试通道）。

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| 源目录查询 | 按源标识/名称检索；展示源名称、业务域、提供者分组、状态、个人过滤、可见角色等 | 搜索引擎管理员 / 搜索查看员 |
| 调参 | 扫描 cron（图形化七页签选择 + 最近 10 次执行时间预览，与调度器同用 `CronExpression` 解析）、增量水位列、每批条数、分片数、跳转模板、结果可见权限码、可见角色多选（候选拉基座角色接口，空=不限制）、业务域、个人数据过滤开关 | 搜索引擎管理员 |
| 启用 / 停用 | 停用后该源不参与本租户检索；MQ 事件对已停用源告警丢弃 | 搜索引擎管理员 |
| 手工登记源 | 调试通道：手工录入源描述（无业务接入时的验收路径） | 搜索引擎管理员 |
| 字段配置 | 维护本租户索引的检索字段：手工添加 / 从数据采样 / 从业务目录导入（同名字段同类型合并、类型冲突整条排除）；驱动 ES mapping、extra 顶层提升与 multi_match/高亮字段组装（单源上限 100） | 搜索引擎管理员 |

## 三、任务中心（索引运维任务）

任务按归属租户创建与执行，作用域 = 本租户索引；多实例防重入（状态 CAS 抢占 + Redisson 分布式锁）。

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| 全量重建 | 删本租户该源索引重建 + 水位归零重扫，保证无孤儿文档；字段集合/类型变更后必须执行 | 搜索引擎管理员 / 搜索运维员 |
| 索引优化 | force-merge 合并段，降低存储与提升查询 | 搜索引擎管理员 / 搜索运维员 |
| 立即扫描 | 从当前水位增量同步（不等价于重建） | 搜索引擎管理员 / 搜索运维员 |
| 闲时执行 | 重建/优化默认 `idleOnly`：仅在闲时窗口（默认 00:00-07:00，可配分段/跨天）执行，工作时间触发则挂起等待 | —（机制） |
| 立即执行（翻转） | 挂起任务行内「立即执行」把 idleOnly 翻转为 0，调度器下一轮拾起 | 搜索运维员 |
| 任务列表 | 任务号/类型/目标源/执行方式/状态（待执行/执行中/成功/失败）/进度/处理条数/失败原因 | 搜索查看员 |

## 七、搜索配置（租户字段定制）

租户级检索字段覆盖（`search_tenant_field` 表，租户隔离），与源管理字段配置的「管理端资产」分层：

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| 覆盖已声明字段 | 只能引用源已声明字段，仅调可搜/权重/高亮/展示/显示名，不能改类型 | 搜索引擎管理员 |
| 从业务目录新增 | 实时拉取业务 `fieldCatalog` 勾选未收录字段（携带类型进入本租户 mapping；保存时对照业务目录校验；单源上限 50） | 搜索引擎管理员 |
| 恢复默认 | 清除本租户覆盖，回退源级配置 | 搜索引擎管理员 |

字段四级输入体系（逐层递进，详见工程 README 第六节）：**编码默认**（业务 `SearchFieldDescriptor` 声明）→ **业务字段目录**（`fieldCatalog` 实时拉取，不落库）→ **源字段配置**（源管理维护，驱动 mapping/提升/查询组装）→ **租户覆盖/新增**（本页）。系统保留字段（title/content/tenantId/permissionCode/visibleUserIds 等过滤字段）任何路径均不可占用。

## 九、增量引擎（后台调度）

| 功能点 | 说明 |
| --- | --- |
| 定时扫描（基线） | 调度器遍历归属上下文（平台 + 全部租户，`runAs` 切归属库），按各租户目录 cron 执行；bizId 散列分片并行拉取，拉取请求携带 `tenantId`（供数端显式过滤），游标按租户 × 源 × 分片独立记账（崩溃续扫）；忙时限流（批间 500ms）、闲时窗口内全速 |
| MQ 实时事件 | 业务写操作后发 `SearchIndexTopics.TOPIC`（`mse-search-index`）`doc_upsert`/`doc_delete`；按事件租户目录校验源——未登记抛错重投（等播种自愈）、已停用告警丢弃；**删除必须走 MQ**（MP 逻辑删除不更新 update_time，扫描覆盖不到） |
| 写入护栏 | 扫描写入侧按当前扫描租户二次过滤文档（`doc.tenantId == 扫描租户`），旧版全租户供数器混跑期不串写 |
| 闲时任务窗口 | `mse.search.idle-window`（默认 00:00-07:00，支持逗号分段与跨天）；idleOnly 任务仅窗口内执行、窗口内扫描批间不限流 |
| 多实例防重入 | 任务状态 CAS 抢占 + Redisson 分布式锁（扫描锁按租户 × 源，任务锁按任务 id） |

## 十、三层权限过滤（查询侧强制注入，不信任前端）

1. **租户隔离**：`tenantId` 取自 TenantContext（缺失快速失败）；目录与索引双重隔离——只在会话租户自己的目录启用源、自己的索引上检索；文档 `_id = {tenantId}:{sourceCode}:{bizId}`，`tenantId` 字段保留为防御过滤。
2. **来源可见性**（权限码 + 可见角色，同时生效、任一不满足即整源不可见）：`permissionCode` 为业务契约字段（管理端可调）；`visibleRoles` 为管理端调参资产（业务重推不覆盖），用户持有任一配置角色才可见。
3. **个人数据范围**（与底座 `@DataPermission` 五档同语义）：文档 `ownerUserId`/`deptId`/`visibleType`（`all`=公开）/`visibleUserIds`；源开关 `dataScopeEnabled`（默认开，公告类无归属源可关）；范围解析单体复用本地 `DataScopeParamResolver`、微服务经 api-system 契约 RPC（异常保守降级「仅本人」），均可自定义 Bean 整体替换。

## 十一、业务接入专节（新业务三步，只动业务工程）

### 11.1 接入三步

1. **引依赖**（业务 service 模块）：`vip.mseapp:search-api:1.0.0-SNAPSHOT`（私服需先 `mvn install` mse-search）；
2. **声明源 + 数据提供者**：自动装配类里 `@Bean` 声明 `SearchSourceContributor`（源编码/名称/域/跳转模板/权限码/字段默认值，按 Bean 名判重）；`@Component` 实现 `RemoteSearchDataProvider`（`providerGroup` 返回本服务名；`fetchBatch` 按 `tenantId` 显式过滤、update_time 水位 + `MOD(bizId, shardCount)` 分片、逻辑删除行 `deleted=true` 返回）；
3. **（可选）实时通道**：微服务 boot 引 `mq-starter`，写操作后发索引事件（**删除务必发**）。

### 11.2 已接入现状（仓库内）

| 业务工程 | 源标识 | 名称 | 跳转 | 结果可见性 |
| --- | --- | --- | --- | --- |
| mse-oa（oa-bpm） | `search:oa:instance` | OA 审批单 | `/sub/oa/detail/instance/{extra.instanceId}` | `oa:process:mine` + 发起人数据范围 |
| mse-oa（oa-form） | `search:oa:form-data` | OA 表单数据 | `/sub/oa/form/data/{bizId}` | `oa:form:data:list` + 发起人数据范围 |

两源均归属「OA域」，经统一 `OaSearchDataProvider` 供数（微服务由 oa-boot 按 group 导出）；oa-form 另实现 `fieldCatalog` 实时暴露已发布表单控件目录；OA 写操作经 `OaSearchIndexPublisher` 发 `doc_upsert`（AFTER_COMMIT，回滚不产生事件）。

### 11.3 降级语义（全程可选依赖）

| 场景 | 表现 |
| --- | --- |
| mse-search 未启动（微服务） | 源目录推送失败仅 warn + 周期重试，业务启动零阻塞 |
| 单体未聚合 mse-search | 推送器本地无实现，warn 一次后停止；`mse.search.registry.enabled=false` 可整体关闭 |
| 未配置 RocketMQ | 事件发送 noop / 未引 mq-starter 直接跳过——增量由定时扫描兜底 |
| Elasticsearch 未启动 | 仅搜索索引/查询不可用，业务零感知 |

## 十二、目录租户化（终态说明）

源目录/扫描/任务/索引按租户归属是本工程的**当前终态**（背景：源管理等页面已转租户端拥有，早期「全局目录 + 租户路由」方案会导致独立库租户目录永远为空，已退役）：

| 侧面 | 终态 |
| --- | --- |
| 数据模型 | `search_source` / `search_task` / `search_scan_cursor` / `search_hot_keyword` / `search_tenant_field` 五表全部带 `tenant_id` 与租户维度唯一键（BaseEntity 租户隔离）；`V20261001_02_search__search_init.sql`（master 通道，主库与懒初始化租户库）+ `V20261001_03_search__search_platform.sql`（base + platform 通道，平台库副本，范式同 monitor） |
| 目录播种 | 业务自注册的源描述由 `SearchSourceFleetSeeder` 扇出播种至「平台 + 全部租户」归属上下文（逐上下文 `runAs`，路由拦截器切归属库）；单上下文失败等下轮推送自愈，新租户建库后最迟一个推送周期（默认 5 分钟）目录自动就绪 |
| 存量迁移 | 升级后主库旧目录行 `tenant_id=0` 即平台自有目录；各租户目录按描述符默认重建（租户级调参历史不迁移），租户游标为空 → 首扫从水位 "0" 全量重建租户索引，无需数据迁移 |
| 索引分桶 | 每租户 × 每源一个索引 `{index-prefix}-{sourceCode 小写、':'→'_'}-{tenantId}`；旧共享索引 `mse-search-*` 成孤儿数据可选手工清理；mapping/字段类型/新增字段完全租户自治，重建与清理互不影响 |
| 契约约束 | `FetchBatchRequest` 携带 `tenantId`（供数端显式按其过滤）；写入侧按扫描租户二次过滤兜底——旧版供数器混跑期不串写，但只能供出平台域数据，search-boot 与业务 boot 需同批升级 |

> 平台域（tenant 0）不是"共享层"而是**一个独立世界**：平台自有目录/索引只服务平台世界的数据与使用场景，租户检索不读平台行、平台检索不读租户行（三层过滤第一层强制保证）。
