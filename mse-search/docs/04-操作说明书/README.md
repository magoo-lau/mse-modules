# 04 操作说明书 —— 总览与使用指南

> MSE-Search 搜索引擎服务**分角色操作说明书**总览。每本手册面向一个岗位，讲清「这个岗位能做什么、在哪个页面做、按什么顺序做」。
> 功能全景见 [01-功能规划](../01-功能规划.md)；角色授权设计依据见 [03-角色规划](../03-角色规划.md)。手册描述以当前系统实际界面为准。

## 二、进入系统

1. 用企业账号登录**基座门户**（浏览器访问门户地址）。
2. 登录后在左侧导航找到「**搜索引擎**」分组目录（租户端展开即见源管理、任务中心、热词统计、搜索测试、索引管理、搜索配置六个页面）。菜单按你的角色授权显示——看不到某个菜单表示该角色未授权或套餐未包含。
3. **不进搜索引擎页面也能用搜索**：顶栏搜索框与首页「全局搜索」卡片对所有登录用户开放。
4. 界面为微前端嵌入运行：导航、登录态、深浅色主题均由基座统一管理，搜索引擎页面内不再单独登录。

## 三、普通用户：搜索怎么用（通用操作）

1. **入口**：顶栏搜索框（随时可用）或首页「全局搜索」卡片（首页「添加卡片」自主启用；管理员可在「首页配置 → 布局设计」调整顶栏开关）。
2. **输入即搜**：输入关键词回车（或点放大镜），返回高亮命中结果，带来源、摘要与更新时间。
3. **按域过滤**：输入框下方有「全部域 + 各域」标签（如「OA域」）——点某个域只搜该业务的数据；没有域标签表示当前无可分域的源。
4. **点击直达**：点结果跳到对应业务页面详情（如 OA 审批单详情）。
5. **为什么搜不到**——按序自查：
   - 数据还没接入搜索（业务工程未声明可搜索源，或该类数据本就不在搜索范围）；
   - 你没有该业务的查看权限（如 OA 审批单需要 `oa:process:mine`——与业务列表页同口径）；
   - 数据的归属人不是你、部门不含你、也没共享给你（按发起人范围过滤的数据只对范围内的人可见）；
   - 数据刚产生还在索引路上（定时扫描有周期，属正常延迟）。
   以上均属正常设计，不是故障；确需扩大可见范围找租户管理员。

## 四、系统业务全景

```
业务数据（OA 审批单 / 表单数据 / …各业务自注册的可搜索源）
  → 源目录登记（自动推送，每租户一份目录）
  → 增量索引（定时扫描 + 业务实时事件；删除即时清理）
  → 用户在基座顶栏 / 首页卡片搜索 → 按权限过滤（租户 → 来源 → 个人范围）→ 高亮结果
  → 点击跳转业务详情页
管理员配套：源管理（调参/字段）、任务中心（重建/优化/扫描）、索引管理（浏览/清理）、搜索测试（验收）
```

## 五、状态字典速查（界面标签的准确含义）

| 业务对象 | 状态枚举 |
| --- | --- |
| 可搜索源 | 启用 / 停用（停用后不参与本租户检索） |
| 运维任务 | 待执行 → 执行中 → 成功 / 失败（失败原因在列表可见） |
| 执行方式 | 仅闲时（默认：全量重建/索引优化在闲时窗口 00:00-07:00 内执行，工作时间触发则挂起等待）/ 立即 |
| 索引健康 | 绿 / 黄 / 红（Elasticsearch 集群健康色） |
| 文档可见类型 | 默认（按归属人/部门范围过滤）/ 公开 all（全员可见） |
| 任务类型 | 全量重建（删索引重建+水位归零）/ 索引优化（force-merge）/ 立即扫描（从当前水位增量） |

## 六、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 左侧看不到「搜索引擎」菜单 | 该角色未授权此菜单，或租户套餐未包含。联系租户管理员在「角色管理 / 套餐管理」检查。 |
| 顶栏搜不到某个业务的数据 | 见第三节第 5 条自查清单；多为权限过滤或数据未接入，属正常设计。 |
| 别人能搜到、我搜不到同一条数据 | 个人数据范围过滤生效（数据归属人/部门/共享范围不含你）。找租户管理员或数据归属人处理。 |
| 刚改完的数据搜出来还是旧内容 | 增量有扫描周期；业务发出实时事件的场景是即时的。急迫时可请管理员执行「立即扫描」。 |
| 刚删掉的数据还能搜到 | 删除依赖业务实时事件通道；未接 MQ 的业务由扫描周期兜底。持续残留请管理员到索引管理核对该文档。 |
| 点搜索结果打不开页面 | 业务详情页地址变化或无该页面权限；先确认自己能在对应业务应用里打开该数据。 |
| 看到搜索结果但摘要不显示额外字段 | 该源未配置展示字段或字段未收录；联系搜索引擎管理员在「搜索配置 / 源管理」补充。 |
