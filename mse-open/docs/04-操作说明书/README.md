# 04 操作说明书 —— 总览与使用指南

> MSE-OPEN 开放平台**分角色操作说明书**总览。每本手册面向一类使用者，讲清「这个角色能做什么、在哪个页面做、按什么顺序做」。
> 功能全景见 [01-功能规划](../01-功能规划.md)；角色授权设计依据见 [03-角色规划](../03-角色规划.md)；业务接入与第三方调用的技术细节见 [open-api-guide.md](../open-api-guide.md)。手册描述以当前系统实际界面为准。

## 一、手册索引（按角色领取）

| 手册 | 使用者 | 管理入口 | 一句话定位 |
| --- | --- | --- | --- |
| [01-开放平台管理员](01-开放平台管理员.md) | 开放平台管理员（平台端 / 租户端管理员） | 开放能力 → 应用管理 / API 目录 / 调用日志 / 身份绑定 | 建应用发凭证、授权 API、目录治理、调用审计 |
| [02-接入方开发者](02-接入方开发者.md) | 第三方系统 / 内网系统的开发人员 | 无管理页面（持应用凭证调用） | 从申请凭证到联调上线的完整流程 |

> 角色分配：管理端功能点（12 个）由管理员在基座「角色管理 → 授权」按 [03-角色规划](../03-角色规划.md) 勾选；接入方开发者不进管理端，只与应用凭证打交道。

## 二、进入系统

1. 用平台账号或租户账号登录**基座门户**（浏览器访问门户地址）。
2. 登录后在左侧导航找到「**开放能力**」分组目录，展开即见全部页面：应用管理、调用日志、身份绑定、接入指南、API 目录。菜单按你的角色授权显示——看不到某个菜单表示该角色未授权或套餐未包含。
3. 界面为微前端嵌入运行：导航、登录态、深浅色主题均由基座统一管理，开放平台页面内不再单独登录。
4. **两端视角**：租户账号进来管理**本租户**的开放应用（绑定租户自动填充、不可改选）；平台账号进来可治理**平台域**应用并能为应用绑定任意租户。两边互不越界。

## 三、系统业务全景

```
业务系统自注册目录（oa/mp/data/ai/fs 等把自有能力挂到统一清单）
  → 管理员在「API 目录」查看全量清单、按需停用（即时生效）
  → 接入方提交接入申请
  → 管理员在「应用管理」建应用 → 发放 AppKey/AppSecret（明文仅展示一次）
  → 管理员给应用「授权」可调用的 API → 按需配置限流/过期/签名/白名单
  → 接入方换取 access_token（默认 2 小时）→ 调用开放接口
  → 每次调用经鉴权链校验并记入「调用日志」（含被拒绝的调用）
```

开放平台管的是**统一窗口**：凭证、目录、授权、限流、审计全部在这里；背后的用户/部门/角色能力与各业务能力（OA 流程、AI 对话、文件等）由各业务系统提供，接入方无感知。

## 四、通用操作（所有页面一致）

- 筛选区在列表上方：文本框输入后按**回车**或点「查询」触发；下拉筛选选中即刷新。
- 列表分页显示，配合筛选缩小范围。
- 高危操作（删除应用、重置密钥）均有二次确认弹窗；**AppSecret 只在创建/重置成功的那一刻弹窗展示一次**，关闭后无法再查看——请当场妥善保存。
- 深浅色模式与主题色跟随基座门户设置，页面自动跟随。

## 五、状态字典速查（界面标签的准确含义）

| 业务对象 | 状态枚举 |
| --- | --- |
| 接入应用 | 启用 / 停用（停用后该应用全部凭证立即失效）；另有 逻辑删除（列表不显示） |
| 凭证过期 | 长期 / 具体时间点（过期后换 token 与调用均失败） |
| 限流 QPS | 具体数值 / 「默认」（未单独配置，用平台默认值） |
| API 目录来源 | 内置（平台种子端点）/ 自注册（业务系统推送） |
| API 目录状态 | 启用 / 停用（停用即时生效，本世界所有应用调用即 404） |
| 调用日志状态码 | 200 成功；401 凭证缺失/无效/过期；403 未授权；404 未开放或已停用；429 超限流；500 业务失败；503 业务系统未部署 |
| 身份绑定 | 一条映射：来源系统 + 外部用户标识 ↔ 中台账号（无状态流转，可解绑） |

## 六、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 左侧看不到「开放能力」菜单 | 该角色未授权此菜单，或租户套餐未包含。联系管理员在「角色管理 / 套餐管理」检查。 |
| AppSecret 忘记保存了 | 无法找回（加密存储）。在「应用管理」点「重置密钥」重新生成，并更新接入方配置。 |
| 接入方反馈调用返回 401 | 凭证错误/过期、应用被停用或删除、改绑了租户。先看应用状态，再让接入方重新换 token。 |
| 接入方反馈 403 | 应用未被授权调用该 API。在「应用管理 → 授权」勾选对应条目保存。 |
| 接入方反馈 404 | API 已停用（「API 目录」查状态）或路径/方法不在清单。注意：目录停用是**全量下线**，应用未授权才是 403。 |
| 接入方反馈 429 | 触发应用限流。按需调高该应用的限流 QPS，或让接入方做退避重试。 |
| 接入方反馈 503 | 目标业务系统未部署或未启动（目录条目仍在）。确认业务服务恢复后自动可用，无需重启开放平台。 |
| 「API 目录」里某个条目想临时下线 | 目录页「停用」该条目，即时生效；恢复用「启用」。业务系统下次重推不会覆盖你的启停状态。 |
| 调用日志里很多 401 | 多为接入方 token 过期未刷新或凭证配错；按应用与 IP 定位后通知对应接入方。 |
