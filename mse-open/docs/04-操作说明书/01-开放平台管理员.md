# 01 开放平台管理员操作手册

> 角色：开放平台管理员（租户端建议角色 `open_admin` / 平台端建议角色 `open_ops`，见 [03-角色规划](../03-角色规划.md)）｜数据范围：租户端管本租户，平台端管平台域并可为应用绑定任意租户｜菜单：「开放能力」分组全部页面。
> 定位：开放平台的管理者——负责**接入应用与凭证**、**API 授权**、**目录治理**、**调用审计**。**不负责**业务系统自身的功能运维（那是各业务系统管理员的事）。

## 一、职责与页面清单

| 职责 | 页面 |
| --- | --- |
| 接入应用建档、发放与重置凭证、启停、限流与有效期配置、安全加固（签名/IP/域名白名单） | 应用管理 |
| 给应用勾选可调用的 API（含业务系统自注册条目） | 应用管理 → 授权 |
| 开放 API 清单查看与启停治理 | API 目录 |
| 调用审计检索（成功与被拒绝的调用全量可查） | 调用日志 |
| 外部标识与中台账号映射关系的查询核对 | 身份绑定 |
| 对接方式自查（内置对接说明，与交付文档同源） | 接入指南 |

## 二、应用管理（日常主页面）

> 路径：开放能力 → **应用管理**。列表展示应用名称、AppKey、绑定租户（平台端可见）、限流 QPS、凭证过期、状态与备注。

### 2.1 接入一个新应用（典型流程）

1. 点「**接入应用**」：填应用名称（必填）、备注；平台端还需选**绑定租户**（含「平台域」选项；租户端自动填充本租户、不可改）。
2. 可按需预填：限流 QPS（留空用平台默认）、凭证过期时间（留空长期）。
3. 保存后弹出「**应用凭证**」窗口：展示 AppKey 与 AppSecret——**仅此一次**，请当场通过安全渠道交给接入方（窗口提示：关闭后无法再次查看；泄露请立即重置密钥）。
4. 点「**授权**」给应用勾选可调用的 API（左侧按业务域分类，右侧接口表勾选；含「自注册」来源条目），保存即生效。
5. 把「接入指南」页（或交付文档 open-api-guide.md）给到接入方，对方即可换取 token 开始联调。

### 2.2 日常维护操作

| 操作 | 说明 |
| --- | --- |
| 编辑 | 改名称/备注/绑定租户（平台端）/限流 QPS/过期时间/白名单与签名开关 |
| 启停 | 停用**即时生效**：该应用全部有效 token 立即失效（每次调用实时回查状态），启用后接入方重新换 token 即可 |
| 重置密钥 | AppSecret 泄露或人员变动时使用；新密钥同样仅展示一次，旧密钥立即作废 |
| 删除 | 二次确认；授权关系与有效凭证一并失效，列表不再显示 |

### 2.3 安全加固（对外暴露的应用建议全开）

在新增/编辑表单中配置：

- **请求签名**：开启后接入方每个请求须附时间戳、一次性随机串与 HMAC-SHA256 签名三个请求头，防窃取与重放；时间戳窗口平台默认 ±300 秒。
- **IP 白名单**：精确 IP 或 IPv4 网段（CIDR），多个用逗号/分号/换行分隔；留空不限制。
- **域名白名单**：裸域名或 `*.example.com` 子域通配；约束浏览器侧来源页（Origin/Referer），适合纯页面侧调用场景。
- **限流 QPS / 凭证过期**：按应用重要性设置配额与有效期，兜底异常调用。

## 三、API 目录（治理页）

> 路径：开放能力 → **API 目录**。全量清单：标识、名称、方法、路径、来源（**内置** = 平台种子端点；**自注册** = 业务系统推送）、分发目标与状态。

- **停用/启用**：对本世界**即时生效**——停用后所有应用调用该 API 一律 404；重新启用即恢复。租户端停用只影响本租户；平台端治理平台域凭证的目录。
- **定义字段（名称/路径/方法/目标）由业务系统重推维护**，管理端只做启停治理：业务系统调整定义会自动更新，你的启停状态与各应用授权**永不被覆盖**。
- 业务系统未部署时条目仍在（调用返回 503 并提示服务不可用），便于提前授权、择日联调。

## 四、调用日志（审计页）

> 路径：开放能力 → **调用日志**。全部 `/open/api/**` 调用（**含被拒绝的** 401/403/404/429）异步记录。

- 筛选：按应用、HTTP 状态码、时间段、关键字检索。
- 每条记录：应用、命中的 API 标识、方法/路径、来源 IP、状态码、耗时、失败原因、链路追踪 ID（TraceId，排查跨系统问题时报给开发）。
- 审计口径：401 多为凭证问题（过期/配错/应用停用）；403 = 未授权（去应用授权勾选）；429 = 超限流（评估是否调 QPS）；503 = 业务系统未部署。

## 五、身份绑定（查询页）

> 路径：开放能力 → **身份绑定**。外部系统用户标识 ↔ 中台账号的映射台账，只读。

- 用途：接入方在做单点登录或消息归人时，会建立「来源系统 + 外部用户标识 → 中台账号」的绑定；此页用于核对某账号被哪些外部系统映射、排查"一条绑定映射到了谁"。
- 绑定关系的建立与解除由接入方经开放接口完成（同租户同来源同外部标识唯一）；本页支持按用户/来源系统检索，不做修改。

## 六、管理员注意事项

1. **凭证即大门**：AppSecret 等同密码——只在弹窗展示一次，走安全渠道交付，绝不进聊天群/邮件明文；怀疑泄露先「重置密钥」再通知接入方。
2. **授权最小化**：按接入方实际需要勾选 API，用不到的不授；开放写接口（创建用户、发起流程等）的授权要双人复核。
3. **启停优于删除**：暂停合作用「停用」，历史审计与配置都保留；确认不再合作再删除。
4. **目录停用是全量开关**：影响本世界所有应用；只想掐某一应用，用「应用管理」里该应用的授权或启停。
5. **换密钥需重置凭证**：平台更换落库加密密钥后历史密文不可解——实施侧会提前通知，届时逐应用「重置密钥」并同步接入方。
