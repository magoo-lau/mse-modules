# 04 操作说明书 —— 总览与使用指南

> MSE-IM 即时通讯**分角色操作说明书**总览。每本手册面向一类使用者，讲清「这个角色能做什么、在哪个页面做、按什么顺序做」。
> 功能全景见 [01-功能规划](../01-功能规划.md)；角色授权设计依据见 [03-角色规划](../03-角色规划.md)。手册描述以当前系统实际界面为准。

## 一、手册索引（按角色领取）

| 手册 | 使用者 | 界面入口 | 一句话定位 |
| --- | --- | --- | --- |
| [01-平台管理员](01-平台管理员.md) | 平台运营 | 基座平台端 →「即时通讯管理 → IM 开通」 | 为租户开通专属 IM 实例，实例全生命周期运维 |
| [02-租户管理员](02-租户管理员.md) | 租户管理侧 | 基座租户端 →「即时通讯」（IM 设置 / 机器人 / 工作台配置） | 实例绑定与部门群、机器人接入 AI、工作台宫格与外部应用免登 |
| [03-普通用户](03-普通用户.md) | 全体员工 | 聊天客户端（Web 地址由管理员提供） | 登录聊天、单聊群聊、音视频通话、工作台免登跳转 |

> 角色分配：普通员工**不需要任何角色**即可使用聊天与工作台（登录即可）；三个管理页面按 [03-角色规划](../03-角色规划.md) 的建议角色由租户/平台管理员在基座「角色管理」授权。所有人可见的菜单还受租户「套餐」勾选的上界约束。

## 二、进入系统

1. **聊天客户端**：浏览器打开管理员提供的聊天客户端地址，用**基座企业账号密码**登录（与登录基座门户是同一套账号，无需单独注册）——用户体系唯一真源是基座，IM 侧不设独立注册。
2. **管理页面**：登录**基座门户**后，租户端左侧导航找到「**即时通讯**」分组目录（IM 设置 / 机器人 / 工作台配置）；平台管理员在**平台端**找到「**即时通讯管理**」分组（IM 开通）。看不到菜单 = 角色未授权或套餐未包含。
3. 管理页面为微前端嵌入运行：导航、登录态、深浅色主题均由基座统一管理，页面内不单独登录。
4. 聊天客户端与基座门户的会话相互独立：客户端本地记住登录（默认 30 天），失效自动回登录页并预填账号。

## 三、系统业务全景

```
平台管理员开通租户专属 IM 实例（或租户自助绑定自建/托管实例）
  → 员工用基座账号登录聊天客户端（首次登录自动注册进实例）
  → 聊天：单聊 / 群聊 / 部门群（自动建并自动维护）/ 图片语音视频文件 / @ / 引用 / 转发
  → 通话：1v1 语音视频（LiveKit）
  → 机器人：群内 @bot 或单聊直发 → 绑定的 AI 智能体自动回复
  → 工作台：宫格入口 → 一次性免登直达基座各模块或外部应用
  → 治理：消息审计落库 · 停用账号即时踢线 · 在线状态可查
```

## 四、通用操作

### 4.1 列表与筛选（管理页面）

- 筛选区在列表上方：文本框输入后按**回车**或点「查询」触发；分页显示。
- 表单保存成功有绿色提示；失败红色提示并给出原因。

### 4.2 外观

聊天客户端与 im-ui 管理页均支持深浅色：管理页跟随基座门户设置（门户右上角切换）；聊天客户端有独立的深浅色切换（右上角设置）。

### 4.3 密码与账号

聊天客户端登录即基座登录：改密、停用、多端登录策略全部沿用基座规则（同端互踢、可在基座「登录设备」自助下线）。账号停用后：客户端无法再登录，已登录的设备在下一次上线校验时被强制下线。

## 五、状态与名词速查

| 名词 | 含义 |
| --- | --- |
| IM 实例 | 该租户专属的一整套聊天服务端（独立部署、独立存储）；「平台托管」= 平台开通页代建，「租户自助」= 租户自己的服务器或第三方托管 |
| 台账 | 实例绑定记录（每租户一条）；停用台账 = 该租户的聊天功能整体关闭 |
| 部门群 | 按部门自动建的群：群名 =「{部门名}群」，群主 = 部门负责人，成员随部门在职名单自动同步（调离自动移出） |
| 机器人 | 群里/单聊里能自动回复的 AI 助手账号（昵称多为「机器人」），由租户管理员绑定到 AI 平台的智能体 |
| 工作台 | 聊天客户端里的「应用宫格」页签：点图标免登直达基座各模块页面或外部系统 |
| 免登（SSO） | 点宫格不需要再输账号密码——客户端签发一次性通行码，目标页面自动兑换成你的登录态 |
| 免登授权（外部应用） | 外部系统（如客户工单）接入后，点宫格打开时自动带上你的身份，外部系统无需再建账号 |
| 连通测试 | 「IM 设置」页的体检按钮：验证实例密钥可用、回调通道可达 |
| webhook 回调 | 实例把「谁上线了 / 谁发了消息」反向通知给平台（机器人与停用踢线依赖此通道） |
| 消息审计 | 外发消息的摘要记录（发送者/接收对象/类型/文本摘要），供合规留档 |

## 六、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 左侧看不到「即时通讯」菜单 | 租户套餐未勾选，或你的角色未授权该菜单。联系租户管理员检查「套餐管理 / 角色管理」。 |
| 聊天客户端登录失败提示「IM 功能未开通」 | 该租户实例未开通或已停用。联系平台管理员（托管实例）或按 [02-租户管理员](02-租户管理员.md) 检查台账启用状态。 |
| 登录成功但收发不了消息 | 实例连通异常：租户管理员在「IM 设置」点「测试连接」按提示排查；也可能是本机网络到实例地址不通。 |
| 看不到某个管理按钮 | 按钮按权限显隐：无该操作权限的角色不显示。找租户管理员补授权（对照 03-角色规划）。 |
| 部门群里没有我 / 有人该退没退 | 部门群随在职名单自动对账（登录后 10 分钟内触发）；租户管理员也可在「IM 设置 → 部门群」点「立即同步」。 |
| @机器人没反应 | 机器人未启用 / 该群不在其群白名单 / 未命中触发关键词（单聊直发始终触发）。租户管理员在「机器人」页检查。 |
| 工作台点图标提示无权限 | 入口配置了「可见角色」而你不在其中。找租户管理员调整入口的可见角色。 |
| 内嵌打开外部应用白屏 | 对方站点禁止被嵌入（安全策略），把入口打开方式改为「弹窗」即可。 |
| 通话听不到/画面卡 | 网络对音视频媒体端口（UDP 段）不通时自动走兜底通道（质量下降不中断）；请管理员检查防火墙放通。 |
| 实例「测试连接」提示回调不可达 | 实例在内网/NAT 后且平台无法反连它：机器人与停用踢线能力受限；平台托管实例不受影响。 |

- 平台运营：读 01 号手册掌握开通与运维动作；部署与故障排查细节见 [05-配置手册](../05-配置手册-零基础版.md)。
