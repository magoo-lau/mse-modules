# 01 平台管理员操作手册（IM 实例编排与运维）

> 使用者：平台运营｜界面入口：基座**平台端** →「即时通讯管理 → IM 开通」。
> 定位：为各租户开通**专属 IM 实例**（一租户一套、物理隔离），并负责实例的全生命周期运维（探活 / 停启 / 备份 / 升级 / 销毁）。**不负责**租户业务侧的机器人与工作台配置（那是租户管理员的事）。

## 一、职责与前置条件

| 职责 | 界面 |
| --- | --- |
| 为租户一键开通专属 IM 实例 | IM 开通页「开通」 |
| 实例健康探查、停用与恢复 | IM 开通页「探活 / 停栈 / 启动」 |
| 实例数据备份、镜像升级 | IM 开通页「备份 / 升级」 |
| 生成接入反代配置交付部署方 | IM 开通页「nginx 配置」 |
| 实例销毁（不可逆） | IM 开通页「销毁」 |

前置条件（由实施方保证，见 [05-配置手册](../05-配置手册-零基础版.md)）：平台已开启「实例编排」能力且部署机可用容器命令；你的账号持有「IM 开通管理」权限（权限点 `im:provision:manage`，挂平台端菜单 520）。

## 二、开通一个租户的实例（典型流程）

1. 进「即时通讯管理 → IM 开通」页。
2. 输入**租户编号**（「租户管理」里该租户的编号）。
3. 点「**开通**」。系统自动完成：渲染专属部署模板 → 分配独立端口块 → 生成全套随机凭据 → 启动整套服务 → 健康检查 → 写入该租户的实例台账。全程约 1~3 分钟，期间请勿关闭页面。
4. ✅ 成功标志：页面提示开通成功；此时该租户员工登录聊天客户端即提示可用。
5. 点「**nginx 配置**」获取该实例的接入反代配置段，交部署方挂到网关/负载均衡（含聊天接口、长连接、媒体、音视频四类路由）；生产环境同时完成域名与证书。

注意事项：

- **已有台账的租户开通会被拒绝**（防止覆盖）：先「销毁」旧实例才能重开。
- 端口块自动顺延分配（每租户一块），无需手工规划；Windows 部署机需避开系统保留端口段（实施方在配置里已处理，见 05 手册）。
- 开通过程失败会**自动清场**：残留的半成品数据被清干净，可安全重试。

## 三、日常运维操作

| 操作 | 用途 | 影响 |
| --- | --- | --- |
| **探活** | 随时体检某租户实例（台账状态 + 实测连通） | 无影响 |
| **停栈** | 临时关闭某租户 IM（如欠费、整改） | 该租户所有聊天客户端立即提示「未开通」；数据保留 |
| **启动** | 恢复已停栈的实例 | 恢复后客户端即可重连 |
| **备份** | 导出该实例全部消息数据与媒体文件到部署机备份目录 | 建议每租户低峰期定期执行 |
| **升级** | 输入新镜像版本号执行滚动升级（如安全补丁） | 数据保留；升级后自动健康等待 |
| **销毁** | 彻底删除实例与全部数据（二次确认） | **不可逆**：数据卷一并删除、台账清除，该租户回到「未开通」状态 |

运维节奏建议：

1. **开通后即备份基线**，此后每周低峰备份一次。
2. 升级遵循「**先测试租户、后生产租户**」灰度；升级前先做一次备份。
3. 停栈前通知租户管理员；销毁前务必取得租户书面确认并完成最终备份。

## 四、与租户管理员的协作边界

| 事项 | 平台管理员 | 租户管理员 |
| --- | --- | --- |
| 实例开通 / 停启 / 销毁 / 升级 / 备份 | ✅（本手册） | 仅可「启停台账开关 + 测试连接」（托管模式下地址密钥对其隐藏） |
| 域名 / 证书 / 反代部署 | 出配置段（nginx 配置按钮） | 配合提供租户接入域名 |
| 机器人 / 工作台 / 部门群 | — | ✅（见 [02-租户管理员](02-租户管理员.md)） |
| 员工账号 | — | ✅（基座组织管理） |

**平台账号不参与聊天**：平台侧账号登录聊天客户端会被拒绝（平台世界不产生 IM 用户），这是设计约定。

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| 开通卡在健康检查后失败 | 查看页面错误详情；多为部署机端口被占用或保留段冲突——实施方调整起始端口配置后重试（失败已自动清场）。 |
| 探活失败但租户说还能用 | 可能该租户是「租户自助」实例（不在平台托管体系）——探活仅对平台开通的实例有意义。 |
| 升级后个别功能异常 | 回退：把镜像 tag 改回上一版本再点「升级」；升级前后均有数据备份兜底。 |
| 租户报「测试连接」回调不可达 | 托管实例由平台代管回调通道，正常应可达；若租户是自建实例则属其自身网络问题（该形态下机器人与停用踢线受限，属已知边界）。 |
