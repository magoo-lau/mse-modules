# 03 普通用户操作手册（聊天 / 通话 / 工作台）

> 使用者：全体员工（**无需任何角色授权，有账号即可用**）｜界面：聊天客户端（Web 地址由管理员提供；移动 App 的接入见文末说明）。
> 定位：用基座企业账号登录，即可与全体同事单聊群聊、发起音视频通话、@AI 机器人提问，并从工作台一键免登直达各业务系统。

## 一、登录与账号

1. 打开管理员提供的**聊天客户端地址**。
2. 输入**基座企业账号密码**登录（与登录基座门户同一套账号；若你的账号开启了二次验证，按提示完成验证）。
3. 登录态本地保留（默认 30 天）：期间刷新或重开浏览器**无需重新登录**；到期或密码改动后回到登录页（已预填你的账号）。
4. **没有「注册」入口**：账号由公司在基座组织管理里统一创建；新员工首次登录聊天客户端即自动开通，无需申请。
5. 多端规则：同类型设备登录会互踢（后登录挤掉先登录），手机与电脑可同时在线；可在基座门户「登录设备」里查看并下线自己的会话。

## 二、聊天

### 2.1 找人发起单聊

左侧「**通讯录**」：按组织架构树找人（支持搜索）——无需加好友，直接点开即聊；点「机器人」分组可与 AI 助手对话。

### 2.2 群聊

- **部门群**：按部门自动建好（「{部门名}群」，群主为部门负责人），成员自动随入职/调离维护——不需要你建、也不支持退出（属正常设计）。
- **自建群**：点「发起群聊」多选同事（可一并选上机器人）；**只有群主和群管理员能拉新人**。
- **群管理**（群资料抽屉，群主可见更多）：改群名 / 群公告 / 全员禁言 / 单人禁言（1 小时 / 24 小时 / 解除）/ 踢人 / 转让群主 / 解散。

### 2.3 消息类型

| 你可以发 | 说明 |
| --- | --- |
| 文字 / emoji | 多行输入，草稿自动保存 |
| 图片 / 视频 | 直接拖入或选择；视频自动生成封面 |
| 语音 | 按住录音（最长 60 秒） |
| 文件 | 任意文件；上传有进度条，可下载 |
| @提醒 | 输入 `@` 选人，或 @所有人 |
| 引用回复 | 消息右键「引用」，对方点击可跳回原消息 |
| 转发 | 单条转发，或多选后「合并转发」（收成一枚可展开的聊天气泡）/「逐条转发」 |
| 名片 | 推荐同事名片，点击直达其资料卡 |
| 链接卡片 | 标题 + 描述 + 链接的结构化分享 |
| 位置 | 发送当前位置（暂以文字坐标呈现，地图显示后续提供） |

### 2.4 消息操作与状态

- **撤回**：自己发出的消息 2 分钟内可撤回（群主/管理员不限时）；**删除**仅从自己这边移除。
- **已读**：单聊可见对方「已读 / 未读」；会话支持置顶、免打扰、标已读、删除。
- **在输入**：对方正在输入时会实时提示；对方在线状态在会话头显示。
- **搜索**：左上角全局搜索，按关键词找历史消息。
- 发送失败的消息可一键**重发**。

### 2.5 AI 机器人

- **单聊直发**给机器人必定触发回复；**群内 @机器人**（或命中管理员设置的关键词）触发。
- 回复由 AI 智能体生成，支持多轮连续追问；群内回复会自动 @ 你。
- 机器人同样可以像同事一样被拉进群。

## 三、音视频通话（1v1）

1. 打开同事单聊，点右上角「语音」或「视频」发起；对方铃声提醒，可选**接听 / 拒接 / 挂断**。
2. 通话中可静音、开关摄像头；对方 30 秒未接听自动取消；对方通话中来电会提示忙线。
3. 没看到通话按钮？你的组织未开启音视频能力（管理员可配），或对方端不支持。

## 四、资料与头像

- 点自己左下角头像或任意同事头像打开**资料卡**：账号 / 部门路径 / 手机 / 邮箱，可「发消息」。
- **自设头像**：点自己的头像上传图片（≤2MB）即刻生效，所有端的消息头像同步更新；「恢复默认」则回落公司在基座里为你设置的头像（再无则显示姓名首字）。

## 五、工作台（一键免登去办公）

聊天客户端顶部「**工作台**」页签是应用宫格：

1. 点任意宫格图标 → **无需再输密码**，直接打开对应页面（基座业务模块在内嵌页打开；外部系统按配置内嵌或新窗口）。
2. 内嵌页面右上角「**分享**」可把当前页面作为卡片发给同事——对方点卡片同样免登直达。
3. 看不到某宫格 = 入口配置了可见角色而你不在其中；需要时找租户管理员。
4. 深浅色：右上角设置切换，与聊天界面主题独立。

> 安全说明：免登通行码为 60 秒一次性凭证，不可转发复用；页面分享卡片仅当链接属于本公司工作台域名时才附带免登，外链不会泄露你的登录态。

## 六、移动端（App）

原生移动 App（Android 先行）正在推进中，登录、聊天、工作台体验与 Web 一致（手机与电脑可同时在线）。接入约定与进展见 [mobile-client.md](../mobile-client.md)；上线前请先使用 Web 端，或在手机浏览器打开基座门户使用移动版页面。

## 七、常见问题

| 现象 | 处理 |
| --- | --- |
| 提示「IM 功能未开通」 | 本公司聊天服务未开通或临时停用，联系租户管理员/平台管理员。 |
| 找不到某位同事 | 通讯录只显示在职员工；若刚入职，让其登录一次聊天客户端（自动注册）后即可见。 |
| 消息发了对方没收到 | 消息带红色感叹号 = 发送失败，点重发；对方离线时消息会正常送达（上线可见），无需重发。 |
| 语音/图片发不出去（一直转圈） | 多为网络到媒体服务器不通：换网络重试；持续出现请报管理员检查媒体服务地址。 |
| 退不出部门群 | 设计如此：部门群成员随人事自动维护，调离部门自动移出。 |
| 邀请按钮是灰的/没有 | 只有群主与群管理员能邀请入群。 |
| 工作台页面打不开/白屏 | 该入口为「内嵌」而对方站点禁止嵌入：请管理员改为「弹窗」打开。 |
| 忘记密码 | 走基座门户登录页的找回流程（聊天与门户同一账号）。 |
