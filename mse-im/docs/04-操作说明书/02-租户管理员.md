# 02 租户管理员操作手册（IM 设置 / 机器人 / 工作台配置）

> 使用者：租户管理侧（建议角色 `im_admin` 与 `im_workbench_admin`，或租户超管）｜界面入口：基座租户端 →「即时通讯」（IM 设置 / 机器人 / 工作台配置三个页面）。
> 定位：管好本租户的聊天「底盘」——实例绑定与部门群、AI 机器人接入、聊天客户端的应用宫格与外部应用免登。**不负责**实例的开通与底层运维（平台托管时归平台管理员；自建实例的部署见 [05-配置手册](../05-配置手册-零基础版.md)）。

## 一、职责与页面清单

| 职责 | 页面 |
| --- | --- |
| 实例绑定（自助形态）、连通体检、回调指引、部门群管理、在线状态 | IM 设置 |
| 机器人账号接入 AI 智能体（触发词 / 群白名单） | 机器人 |
| 聊天客户端宫格入口配置、外部应用接入与免登授权 | 工作台配置 |

## 二、IM 设置（实例与部门群）

### 2.1 两种形态先分清

- **平台托管**（推荐）：页面顶部有「托管说明」——地址与密钥由平台维护，你只需维护「**启用状态**」开关（关闭即对本租户整体停用聊天）并可随时「**测试连接**」。
- **租户自助**（自建/第三方托管实例）：填写服务端调用地址、内网 WS 地址、公网地址（生产域名反代形态）、工作台跳转基址、实例管理员账号与**实例密钥**（保存后不再回显；留空保存 = 不修改）。地址有内网安全校验，非白名单网段会被拒绝。

### 2.2 连通测试（改完必做）

点「**测试连接**」：验证实例密钥可用 + 回调通道可达，结果（时间/成败/说明）回显在页面。**回调不可达**的警示含义：机器人和「停用账号踢线」在该实例上不可用（平台托管实例无此问题）。

### 2.3 webhook 回填（自助实例的必配项）

页面展示本租户的**回调地址**（含专属令牌）：把它填到实例的回调配置（webhooks）里并订阅「消息后置 / 在线状态」类事件——机器人应答、停用踢线、在线状态、消息审计都依赖这条反向通道。平台托管实例已代配，无需操作。

### 2.4 部门群

按部门自动建群：「{部门名}群」，**群主 = 部门负责人**（基座「系统管理 → 部门管理」里设置；未设置负责人时回落租户管理员）。成员随部门在职名单自动收敛：入职补拉、调离移出、改名同步群名、部门删除解散群。

- 用户登录聊天客户端后约 10 分钟内自动对账一次；
- 页面「**立即同步**」可手动全量对账，完成后汇报：新建 N 群、改名 N、转让群主 N、补拉 N、踢出 N、解散 N。
- 部门群在聊天客户端受保护：成员看不到「退群 / 解散」按钮（对账会拉回，属正常设计）。

### 2.5 在线状态

「IM 设置」页可查当前在线人员（谁在线、哪些端），供考勤/值班场景参考。

## 三、机器人（聊天里的 AI 助手）

路径：即时通讯 → **机器人**。机器人在聊天里表现为一个普通成员账号，员工单聊直发、或群内 @它即触发 AI 回复。

新增/编辑要点：

| 字段 | 填法 |
| --- | --- |
| bot 账号 | 留空自动生成（`bot_` 前缀），创建后不可改 |
| 昵称 / 头像 | 聊天里的展示名与头像（可选） |
| 智能体编码 | **必填**——AI 平台（mse-ai）里已创建智能体的编码 |
| 触发关键词 | 逗号分隔；**留空 = 群内 @ 即触发**；单聊直发始终触发，不受关键词限制 |
| 群白名单 | 逗号分隔群编号；**留空 = 所有群生效**；通过聊天客户端把机器人拉进群时会自动加入白名单（免手工维护） |
| 启用 | 停用后不再应答（账号保留） |

验证方式：用任意员工账号在聊天客户端给机器人发一条单聊，收到回复即通。机器人回复由 AI 平台生成——AI 服务不可用时机器人会回复「暂时不可用」类降级提示。

## 四、工作台配置（宫格入口与外部应用）

路径：即时通讯 → **工作台配置**。聊天客户端「工作台」页签的应用宫格完全由这里定义；**未配置任何入口时，客户端自动回退展示员工可见的全部基座页面菜单**——多数租户零配置即有可用工作台。

### 4.1 入口管理（覆盖式保存，改完点保存即生效）

两页签：「入口列表」+「可选页面菜单」（勾选生成 mse 页面入口）+「添加外部应用」按钮。每行可配：

| 配置 | 说明 |
| --- | --- |
| 启用/停用 | 停用行不出现在客户端 |
| 名称 / 分组 | 覆盖默认标题；分组名决定宫格分区（留空按菜单目录推导，外部应用默认归「外部应用」组） |
| 图标 | emoji 字符或图片地址，也可点「上传图标」（≤2MB 常见图片格式） |
| 打开方式 | **内嵌**（客户端内嵌网页）或**弹窗**（新窗口）；对方站点禁止被嵌入时选弹窗 |
| 可见角色 | 多选本租户角色；**留空 = 全员可见**；非空则只有持这些角色的员工可见（跳转时服务端二次复核，绕不过） |
| 排序 | 数字小者靠前 |

### 4.2 添加外部应用（含免登授权）

点「添加外部应用」：名称（必填）、外部系统完整地址（必填 http(s)）、分组、打开方式，以及关键选择——**授权方式**：

- **直连**：打开即跳外部地址，不带身份。
- **免登授权**：选一个本租户的**开放平台应用**（在开放平台「应用管理」预先创建）后保存——员工点宫格时，外部地址自动带上一次性授权码；外部系统凭其应用凭证换取该员工的身份信息（工号/姓名/租户），实现「点开即已登录」。
- 保存成功后系统**只显示一次**应用凭证（app_key 与密钥），请立即复制交给外部系统对接方；泄露或遗忘点「**重置密钥**」换新（app_key 不变）。
- 外部系统的对接报文格式见工程 README「工作台与外部应用免登授权」一节，可直接转给对方开发。

### 4.3 mse 页面入口的免登

勾选「可选页面菜单」生成的入口，点击即免登直达基座对应页面（自动签发一次性通行码，60 秒有效、用后即焚）——无需任何配置。

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| 保存实例密钥后再打开看不到密钥 | 设计如此（安全）：密钥保存后不再回显，留空保存即保持原值；遗忘则到实例侧重置后重新录入。 |
| 「测试连接」失败 | 逐项核对：地址是否可达、密钥与实例侧是否一致、实例是否启动；自助实例先在实例侧自检。 |
| 机器人不回复 | ① 机器人未启用；② 群不在白名单；③ 未命中触发关键词（群聊）；④ AI 平台侧智能体不可用；⑤ 自助实例回调不可达（连通测试会标注）。 |
| 员工说看不到某宫格入口 | 入口停用 / 「可见角色」不含其角色 / 员工角色未授权——三处逐查。 |
| 内嵌外部应用白屏 | 对方站点禁止被嵌入：把该入口打开方式改为「弹窗」。 |
| 免登打开外部应用提示凭证失效 | 密钥被重置或入口被停用：把新凭证重新交给对接方。 |
| 部门群群主不对 | 群主 = 部门负责人：到基座「部门管理」设置/变更负责人，「IM 设置 → 部门群 → 立即同步」后自动转让。 |
