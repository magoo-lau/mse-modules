# 02 权限规划 —— 子应用注册、页面菜单与权限点

> mse-im 的菜单与权限点设计。功能点含义见 [01-功能规划](01-功能规划.md)，角色授权见 [03-角色规划](03-角色规划.md)。
> **本文所有 id 均为已落地的真实值**（种子脚本 `im-service/src/main/resources/db/mysql/V20261001_01_im__im_base.sql`，头指令 `-- mse-target: base`，starter-bridge 自动推送，已登记 alloc-tables.md）。

## 一、规划原则（基座 RBAC 模型）

1. **三张全局表，一条链路**：`sys_micro_app`（子应用注册）→ `sys_menu`（导航菜单）→ `sys_permission`（权限点）；授权链 `sys_user → sys_user_role → sys_role → sys_role_menu / sys_role_permission`。
2. **双端子应用**：im 子应用 **side=3（双端）**——租户端分组目录 516（menu_scope=2）挂 IM 设置 / 机器人 / 工作台配置；平台端分组目录 519（menu_scope=1）挂 IM 开通。同一前端工程 im-ui 按路由承载两端页面。
3. **权限点必须挂靠页面菜单**：9 个权限点全部挂靠本工程 type=3 页面菜单（517/518/520/521），参与角色授权分组与**租户套餐裁剪**；`menu_id=NULL` 通用权限本工程不使用。
4. **聊天使用类端点不设权限点**：`/im/client/**`（会话/资料/头像/通讯录/建群/分享/rtc）、`/im/sso/code`、`GET /im/workbench`、`POST /im/workbench/jump`（登录态复核）均为**登录态鉴权**——普通用户零授权即可聊天与用工作台；权限点只管三个管理页与平台开通页。
5. **免登录端点走网关白名单**（不在权限体系）：`/im/sso/exchange`（一次性 code 兑换）、`/im/oauth/token`、`/im/oauth/userinfo`（外部应用免登授权 OAuth2）、`/im/workbench/asset/*`（图标素材兜底）、`/im/client/asset/*`（自设头像兜底）、`/im/callback/**`（webhook，token 即凭证）。注意 `mse.gateway.ignore-urls` 为整体替换语义，调整须全量列出。
6. **权限码格式**：`im:<模块>:<动作>`，动作小写动词，与仓库 `mes:` / `oa:` 等前缀风格一致；唯一键 `uk_code`。前端按钮用 `v-permission` 按权限码显隐。
7. **落库方式**：随 jar 的幂等版本化脚本（按 id / name 判重，`WHERE NOT EXISTS`），由 starter-bridge 自动推送 mse-system 并经租户库车队重放——**免手工执行**；已应用脚本不再修改，变更一律新增版本文件。

## 五、套餐裁剪与登记纪律

1. **租户套餐**：租户端菜单（517/518/521）需在平台端「套餐管理」勾选后才对租户可见；516 分组目录一并勾选。未配置任何页面菜单的中间状态会退化为单菜单项渲染，建议 516-518、521 一次配齐。平台端菜单（519/520）不进租户套餐，由平台侧角色直授。
2. **license / standalone 裁剪**：随菜单天然生效（tenant-starter 离线交付形态同样以菜单为门控）。
3. **alloc-tables.md 登记情况（已登记）**：后端端口 8099、前端 dev 4030、micro_app id=12、菜单段 516-521、权限段 46xx（4600-4608，基点 4600）、网关前缀 `/im`（白名单 6 条）、sys_config 53201+ 未用、OpenIM 实例端口族（§6b）。后续新增权限点自 **4609 起**顺延并回写登记。
4. **脚本纪律**：全部幂等写法（子应用按 name 判重、菜单按 id 判重、权限点按 id 判重）；历史挂靠修正用条件 UPDATE 幂等补挂；`-- mse-target: base` 脚本不得触碰基座身份表。

## 六、与 515 / 522-529 段的关系

alloc-tables 菜号段中 515 为基座 tenant-starter 离线交付占用、522-529 为新 PC 子应用预留段——im 占用 516-521 与两者无交叉；46xx 权限段整段归 im（45xx 有基座 4501 跨段占用），后续扩展无冲突。
