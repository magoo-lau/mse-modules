> mse-im 功能总纲。配套文档：[02-权限规划](02-权限规划.md)（管理页权限码）、[03-角色规划](03-角色规划.md)（谁能管）；技术细节以仓库根 [docs/tech/openim-integration.md](../../../docs/tech/openim-integration.md) 为准。

## 一、模块总览与核心链路

| # | 模块 | 承载页面 | 状态 | 一句话定位 |
| --- | --- | --- | --- | --- |
| 1 | 实例编排（平台端） | IM 开通（520） | 已落地 | 平台为租户一键开通专属 OpenIM 实例并管理全生命周期 |
| 2 | 实例台账与租户自助 | IM 设置（517） | 已落地 | 实例绑定 / 连通测试 / webhook 回填 / 部门群，每租户一行 |
| 3 | 账号桥与会话签发 | 聊天客户端登录 | 已落地 | 基座账号密码 → IM 会话（userID=sys_user.id，懒供给） |

| 8 | 机器人（IM × mse-ai） | 机器人（518） | 已落地 | bot 账号绑定智能体，单聊直发 / 群内@触发 AI 回复 |
| 9 | 用户资料与自设头像 | 聊天客户端资料卡 | 已落地 | 生效头像三态：IM 自设 > 基座头像 > 首字母兜底 |

**核心业务闭环**：

```
租户开通（平台建租户 + 套餐勾选「即时通讯」菜单）
  → 实例就绪（平台编排开通专属实例 ｜ 租户自助录入自建/托管实例 ｜ standalone 配置段兜底）
  → 用户登录聊天客户端（基座账号密码）
  → 账号桥签发 IM 会话（懒供给注册进实例 + 资料同步 + 部门群保障）
  → 聊天使用（单聊/群聊/媒体/音视频通话/通讯录/机器人）
  → 工作台（宫格入口 → 一次性 ssoCode → 基座各模块免登直达）
  → 治理面（消息审计落库 · 停用即踢线 · 在线状态 · 机器人 AI 应答）
```

## 二、实例编排（平台端，已落地）

平台运营在基座平台端「即时通讯管理 → IM 开通」页操作；底层 `ImProvisionService` 以 `docker/openim/` compose 为模板按租户渲染独立工作目录，经 docker CLI 起栈。

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| 一键开通 | 输入租户编号 → 渲染 compose（剥 container_name / 剥固定端口 / 复制 rpc-auth 覆盖文件）→ 生成端口块与全套随机凭据 → 起栈 → `get_admin_token` 实测探活 → 写 PLATFORM_HOSTED 台账 | 平台管理员 |
| 端口块动态分配 | 扫既有托管实例 apiUrl 端口取最大 +1 顺延一块（api=块基址、ws+1、minio+2、console+3）；block-size=10、首块 port-base=11000；Windows 部署避开 excludedportrange 保留段 | 平台管理员 |
| 生命周期管理 | 探活（status）/ 停栈（stop，台账停用=该租户 IM 关闭）/ 启动（start）/ 销毁（destroy，down -v + 物理删行，不可逆） | 平台管理员 |
| 实例升级 | 改镜像 tag 重建 openim-server 容器 + 健康等待（数据卷保留） | 平台管理员 |
| 实例备份 | mongo `--archive` 导出 + minio 数据卷 tar → backup-dir | 平台管理员 |
| nginx 反代段生成 | 生成同域反代配置段（`/api`、`/msg_gateway`、`/rtc` 等）交付部署方；配置 `domain-template` 子域模板时开通即落 https/wss 公网坐标 | 平台管理员 |

## 三、实例台账与租户自助（已落地）

`im_instance_config` 每租户一行；来源三态：租户自助（TENANT_SELF_HOSTED）/ 平台托管（PLATFORM_HOSTED）/ 配置兜底（yaml，无行）。选址优先级：**台账行（启用）> `mse.im.servers[tenantId]` > 默认段；有行但停用 = 该租户 IM 显式关闭（不回落）**。

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| 实例绑定自助 | 租户录入自建/托管实例：api-url（SSRF 校验）/ 公网坐标 / web 工作台基址 / secret（AES-256-GCM 密文落库、出参不回显、留空不变） | 租户管理员 |
| 连通测试 | `get_admin_token` 验活 + webhook 回调可达性探测，结果回写三列（时间/成败/消息）；托管行租户仅可启停与测试 | 租户管理员 |
| webhook 回填指引 | 页面展示 callbackUrl（token 内嵌），租户填入实例 `webhooks.yml` 并订阅 after 类事件；实例在 NAT 后不可达时测试会明示（机器人/停用踢线受限） | 租户管理员 |
| 部门群管理 | 映射列表（部门/群名/群主/成员数）+ 手动全量对账：新部门建群、改名同步、缺失成员补拉、多余踢出、部门删除解散、群主随负责人转让 | 租户管理员 |

## 四、账号桥与会话签发（已落地）

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| IM 会话签发 | `POST /im/client/session {platformID}` → `{userID, imToken, apiAddr, wsAddr, expireAt, nickname, faceURL, rtc}`；userID=`sys_user.id`，免映射 | 普通用户（登录态） |
| 账号闸门 | 停用用户拒签；平台账号（tenant_id=0）拒绝；签发前经基座契约复核状态 | （内建） |
| 懒供给 | 首次签发注册进实例（重复注册 1102 短路 + `update_user_info` 同步资料）——mse 是昵称/头像唯一真源 | （内建） |
| 部门群保障 | 签发后异步触发部门群对账（10 分钟 Redis 防抖），保障本人已入部门群 | （内建） |
| 资料卡 | `GET /im/client/user/{userId}/profile`：账号/昵称/生效头像/手机/邮箱/部门路径（基座 RPC 拼装，仅启用用户） | 普通用户 |
| 自设头像 | 上传（≤2MB）/ 恢复默认，落 `im_user_profile` 并即时推送实例（他端气泡头像同步）；存储 mse-fs 公开素材通道优先、本地磁盘兜底 | 普通用户 |
| 通讯录 | `GET /im/client/contacts`：部门树（含负责人）+ 启用用户 + 启用机器人 + 部门群 id 集；**好友体系不启用**（组织架构即通讯录，可对任意在职用户/机器人发起单聊） | 普通用户 |
| 按需注册 | `POST /im/client/contacts/ensure`：对未登录过 IM 的用户发起单聊/建群前兜底注册 | 普通用户 |

## 五、聊天客户端 Web（clients/web，已落地）

自研客户端（非官方 demo 改造），Vue3 + `@openim/wasm-client-sdk` 直连实例；深浅双主题自研 CSS 变量；认证存档 localStorage 静默恢复登录，IM token 过期自动重签。

| 能力类别 | 功能点 |
| --- | --- |
| 消息类型 | 文本 / 图片 / 语音（≤60s 录音）/ 视频（自动截帧）/ 文件 / @消息（选人 + @所有人）/ 合并转发 / 名片 / 位置（仅渲染骨架，地图为规划）/ 自定义（链接卡片、页面分享卡片、通话信令）/ 引用回复 / emoji 面板 |
| 消息操作 | 撤回（自己 2 分钟内，群主/管理员不限）、删除、失败重发、复制、引用、单条/合并/逐条转发、合并预览、引用定位、大图查看/视频播放、文件下载 |
| 会话 | 置顶、免打扰、标记已读、删除、草稿持久化、未读角标、上滚分页、全局消息搜索 |
| 状态 | 单聊已读回执、正在输入、对端在线订阅 |
| 群管理 | 建群（多选人 + 机器人）、邀请（仅群主/群管理员，服务端强制校验）、群名/公告编辑、全员/成员禁言、踢人、转让群主、退群、解散；**部门群隐藏退群/解散**（对账自动维护） |
| 音视频通话 | 1v1 语音/视频：自研信令（在线 custom 消息六态：call/accept/reject/cancel/hangup/busy，30s 超时/占线回 busy）+ LiveKit 媒体房间（token 经 `/im/client/rtc/token`）；多人/会议为后续演进（规划） |
| 媒体直传 | 浏览器经预签名 URL 直传实例 MinIO（进度条气泡）；`MINIO_EXTERNAL_ADDRESS` 必须浏览器可达 |
| 页面分享 | 工作台内嵌页「分享」→ 以发送者身份把 app-share 卡片发给联系人/群聊；点击仅同源才免登直达（防骗取会话） |

## 六、工作台与 SSO 免登（已落地）

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| 宫格入口 | `GET /im/workbench`：mse 页面菜单入口（entryType=0，按本人菜单集权限过滤）+ 外部应用入口（entryType=1）；支持分组/图标（emoji 或上传图片）/标题覆盖/排序/打开方式（内嵌 iframe / 弹窗）/可见角色；未配置回退全量页面菜单 | 普通用户（拉取）/ 租户管理员（配置） |
| 入口角色可见性 | `role_ids` 空=全员可见；非空=与本人角色有交集才可见；`/im/workbench/jump` 跳转时同口径复核 403（防绕过客户端直调） | （内建） |
| 工作台 SSO | 点宫格 → `POST /im/sso/code {targetUrl}` → 60s 一次性 code（Redis GETDEL + 绑定目标站点 Origin + 限频 30 次/分）→ 基座路由守卫检测 `?ssoCode` 自动兑换标准租户会话免登直达 | 普通用户 |
| 图标素材 | 上传（≤2MB）/ 本地兜底输出（mse-fs 模式走 `/fs/asset/**`） | 租户管理员 |

## 七、外部应用免登授权（OAuth2，已落地）

外部应用接入微信第三方同款的授权码模式（平台是身份源）：

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| 免登授权绑定 | 工作台外部应用入口选择「免登授权」并关联本租户开放平台应用（凭证归口 mse-open，im 只冗余 app_key）→ 用户点宫格即带一次性授权码跳外部地址（默认 300s） | 租户管理员 |
| token 兑换 | `POST /im/oauth/token`（免登录，服务端到服务端）：`{app_key, app_secret, code}` → `{accessToken, tokenType, expiresIn(7200), user{tenantId,userId,username,nickname}}`；兼容 `client_id/client_secret` 别名与表单/查询参数 | 外部系统（对接方） |
| 用户识别 | `GET /im/oauth/userinfo`（Bearer accessToken）→ 用户身份；入口停用/删除或密钥重置后旧凭证即失效 | 外部系统 |
| 密钥管理 | app_key 全局唯一 `wb_` 前缀；secret 明文仅展示一次，「重置密钥」换新 | 租户管理员 |

## 八、消息审计与在线治理（已落地）

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| 消息外发审计 | webhook `afterSendSingleMsg/GroupMsg` 全量异步落 `im_msg_audit`（发送者/接收者或群/会话类型/内容类型/文本摘要，摘要口径与客户端一致）；**查询界面为规划**，当前仅落库 | （内建） |
| 在线状态 | `afterUserOnline/Offline/KickOff` 维护 Redis presence，`GET /im/online[/list]` 查询 | 租户管理员 |
| 停用即踢线 | 上线复核 mse 账号状态，停用/删除逐端型 `force_logout` 强制下线；改密/禁用后新 token 不再签发 | （内建） |
| 注册旁路拒绝 | `beforeUserRegister` 同步拒绝非「雪花数字 / bot_ 前缀」的注册（防直连实例绕过账号桥） | （内建） |

## 九、机器人（IM × mse-ai，已落地）

v3.8.3 无原生 bot 接口——**普通账号 + webhook 收 + admin 代发回**模式：

| 功能点 | 说明 | 主要角色 |
| --- | --- | --- |
| 机器人绑定 | `bot_` 前缀账号绑定 mse-ai 智能体（agentCode 必填）/ 触发关键词（空=群内@即触发）/ 群白名单（空=所有群）/ 头像；保存即注册进实例 | 租户管理员 |
| 触发与回复 | 单聊直发始终触发；群内 `atUserList` 命中或「引用+@」组合消息（114，atUserList 被客户端丢弃）正文 @昵称 兜底 + 白名单 + 关键词判定 → `RemoteAiChatService.chat`（携带聊天上下文）→ `/msg/send_msg` 代发（群内 AtText @提问者）；AI 失败降级提示；bot 代发消息不触发任何 bot（防环） | 普通用户（使用） |
| 上下文感知 | 触发后从 `im_msg_audit` 消息存档拉本会话最近 N 条（群聊按群、单聊按双向消息流，含机器人自身历史回复），以「昵称: 文本」脚本拼进提问（`ImBotContextService`，审计行带昵称快照）；无 AI 侧会话状态——天然多轮、重启无损、可感知群成员间对话；规模 `mse.im.bot.context-size / context-max-chars` 全局配置 | （内建） |
| 群内引导 | 建群/邀请时可同请求带入机器人；机器人进群即自动追加该群白名单（幂等） | 普通用户 |
