# 04 操作说明书 —— 总览与使用指南

> 文件存储服务（文件管理）**分角色操作说明书**总览。每本手册面向一类使用者，讲清「这个角色能做什么、在哪个页面做、按什么顺序做」。
> 功能全景见 [01-功能规划](../01-功能规划.md)；角色授权设计依据见 [03-角色规划](../03-角色规划.md)。手册描述以当前系统实际界面为准。

## 一、手册索引（按角色领取）

| 手册 | 使用者 | 数据范围 | 一句话定位 |
| --- | --- | --- | --- |
| [01-平台管理员](01-平台管理员.md) | 平台管理员 / 实施运维 | 全平台 | 存储后端选型与切换、历史文件迁移、RustFS 巡检、公开素材治理 |
| [02-租户用户](02-租户用户.md) | 租户用户 / 文件管理员 | 本租户 | 文件上传、大文件直传、检索、下载、直链、删除、图片预览 |

> 角色分配：文件管理页菜单（471）需在租户套餐勾选后可见；普通用户的按钮按权限显隐（查询/上传/下载/删除/迁移五个权限点，建议角色清单见 [03-角色规划](../03-角色规划.md) 第二节，由租户管理员在「角色管理」授予）。**业务模块里的文件能力**（oa 附件、用户头像、登录页品牌素材等）不经过本页面，随各业务模块自身的权限与界面走。

## 二、进入系统

1. 用企业账号登录**基座门户**（浏览器访问门户地址）。
2. 登录后在左侧导航找到「**文件存储**」分组目录，展开即见「**文件管理**」页面。菜单按你的角色授权与租户套餐显示——看不到表示未授权或套餐未包含。
3. 界面为微前端嵌入运行：导航、登录态、深浅色主题均由基座统一管理，文件管理页内不再单独登录。
4. 页面顶部有一个**存储模式标签**（「本地文件存储」或「RustFS 对象存储」），标识当前部署的存储后端，只读展示。

## 三、系统能力全景

```
上传（普通上传 ≤100MB ／ 大文件分片直传·仅对象存储模式）
  → 秒传（同租户传过同一内容的文件，第二次立即完成）
  → 列表管理（文件名/业务分类/时间检索，图片自动出缩略图）
  → 使用（页面下载；复制限时直链分享；登录页素材等免登录场景经公开素材地址加载）
  → 清理（删除：列表移除并尽力清掉物理文件）
运维（平台侧：切换存储后端 local↔RustFS、历史文件一键迁移）
```

各业务模块（附件、头像、品牌素材、知识库等）的文件统一存到这里，但操作入口在各自业务页面；文件管理页是查看与管理全部文件的统一窗口。

## 四、通用操作（所有角色一致）

### 4.1 列表与筛选

- 筛选区在列表上方：**文件名**（模糊匹配）、**业务分类**（如 `oa/attachment`）、**上传时间范围**（日期区间选择），输入后按**回车**或点「查询」触发。
- 列表分页显示（每页 10 条），底部翻页。
- 文件名列：图片类文件自动显示 28px 缩略图（不支持缩略图的类型显示纯文件名）；点缩略图可放大预览。

### 4.2 上传

- 点「**上传文件**」可一次选择多个文件；普通上传单文件上限默认 100MB。
- 「**大文件直传**」按钮仅在 RustFS 模式下出现：适合大文件，浏览器分片直传对象存储，弹窗显示进度，关闭弹窗前请等待完成。
- 同租户上传**内容完全相同**的文件（同内容同大小）会**秒传**——立即完成，不重复占用存储。

### 4.3 下载与直链

- 「**下载**」：浏览器保存原文件（服务端流式，保留鉴权与审计）。
- 「**直链**」（仅 RustFS 模式且管理员开启预签名时显示）：复制一个**限时有效**（默认 1 小时）的直接下载地址，适合发给外部人员或放进文档；到期自动失效，泄露面仅限单个文件。

### 4.4 删除

- 「**删除**」需二次确认：列表移除 + 物理文件尽力删除。若同一内容被同租户多条记录共用（秒传复用），物理文件会保留到最后一处引用删除为止。

### 4.5 外观

深浅色模式与主题色跟随基座门户设置（门户右上角切换），文件管理页自动跟随，无需单独设置。

## 五、名词速查（界面标签的准确含义）

| 界面元素 | 含义 |
| --- | --- |
| 标签「本地文件存储」 | 当前后端为服务器本地磁盘（缺省模式，零外部依赖） |
| 标签「RustFS 对象存储」 | 当前后端为 RustFS 对象存储（S3 兼容，同样适用于 MinIO 等） |
| 标签「直传中」（存储列） | 该文件的大文件分片直传还在进行中，完成约 1 分钟内自动消失并转为正式状态 |
| 存储列「本地」/「RustFS」 | 该文件**上传当时**落在后端——切换存储模式后历史文件仍按原后端寻址，用「迁移历史文件」统一搬移 |
| 按钮「大文件直传」 | 仅 RustFS 模式显示；分片并发直传对象存储，带进度弹窗 |
| 按钮「直链」 | 仅 RustFS 模式且预签名开启时显示；复制限时直接下载地址 |
| 按钮「迁移历史文件」 | 仅持存储迁移权限的角色可见；把另一侧后端的历史文件搬移到当前后端 |

## 六、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 左侧看不到「文件存储」菜单 | 租户套餐未勾选该页面，或角色未授权。联系租户管理员在「套餐管理 / 角色管理」检查。 |
| 看不到「上传文件」按钮 | 该角色未授予「文件上传」权限，找租户管理员补授权。 |
| 看不到「大文件直传」按钮 | 仅 RustFS 模式提供；本地存储模式用「上传文件」（有单文件大小上限）。 |
| 看不到「直链」按钮 | 预签名直链功能默认关闭，由平台管理员在配置中开启（仅 RustFS 模式生效）。 |
| 上传报大小超限 | 普通上传默认上限 100MB；更大的文件在 RustFS 模式用「大文件直传」。 |
| 大文件直传失败提示「未读到分片 ETag」 | 对象存储的跨域配置缺 ETag 暴露头，联系实施运维按部署手册开启 CORS。 |
| 列表里看不到别的租户的文件 | 正常设计：文件按租户双层隔离（列表 + 物理存储），跨租户访问一律不存在。 |
| 图片没有缩略图 | 仅 jpeg/png/gif/bmp 且不超过 20MB 的图片支持缩略图；svg/webp 与超大图显示纯文件名。 |
| 直链打不开了 | 直链限时有效（默认 1 小时），到期请重新复制。 |
| 删除后存储空间没立刻变小 | 物理删除是尽力执行；若该内容被同租户多处引用（秒传复用），会保留到最后一处引用删除。 |
