# 02 租户用户操作手册（文件管理页）

> 角色：文件用户 / 文件管理员｜数据范围：本租户｜菜单：「文件存储 → 文件管理」。
> 定位：日常文件的**上传、检索、下载、分享直链与清理**。各业务模块（附件、头像、知识库等）里的文件也统一存放在这里，可在本页统一查到。

## 一、职责与页面布局

进入「文件存储 → 文件管理」后，页面分三块：

| 区域 | 内容 |
| --- | --- |
| 顶部工具栏 | 筛选条件（文件名 / 业务分类 / 上传时间范围）+「查询」；右侧：存储模式标签、「迁移历史文件」（仅文件管理员）、「上传文件」、「大文件直传」（仅对象存储模式） |
| 中部列表 | 文件名（图片带缩略图）、大小、类型、业务分类、存储、上传时间、操作列（下载 / 直链 / 删除） |
| 底部分页 | 每页 10 条，翻页浏览 |

## 二、上传文件

### 2.1 普通上传（最常用）

1. 点右上「**上传文件**」→ 选择一个或多个文件（可多选）。
2. 上传完成提示「已上传：文件名」，列表自动刷新，新文件出现在最前（按上传时间倒序）。
3. 单文件默认上限 100MB；更大文件见 2.2。

### 2.2 大文件直传（对象存储模式）

「**大文件直传**」按钮只在 RustFS 模式下出现，适合大文件（不占应用服务器带宽，浏览器分片直传对象存储）：

1. 点「大文件直传」选择文件 → 弹出进度弹窗，显示文件名与进度条。
2. **等待进度走完**（弹窗期间请勿关闭页面），完成后提示「已直传：文件名」。
3. 直传过程中列表会出现「直传中」标记的行，完成约 1 分钟内自动转为正式状态；中途失败会自动清理，重新上传即可。

### 2.3 秒传

上传**内容完全相同**的文件（同内容同大小，哪怕文件名不同）第二次会**立即完成**——系统识别重复内容、直接复用已存的那份，不重复占用存储空间。删除其中一条记录不影响其他记录的下载。

## 三、检索文件

| 筛选项 | 用法 |
| --- | --- |
| 文件名 | 模糊匹配，输入部分名称即可，回车或点「查询」 |
| 业务分类 | 按业务模块归档的分类标识精确匹配（如 `oa/attachment` 表示 OA 附件；自己上传的文件此列为「-」） |
| 上传时间范围 | 选日期区间（含首尾两天） |

组合条件为「且」关系；点输入框清除图标恢复全部。

## 四、下载、预览与直链

- **下载**：点操作列「**下载**」，浏览器按原文件名保存。
- **图片预览**：图片文件在文件名列自动显示小缩略图；**点缩略图**弹出大图查看（不支持缩略图的类型——svg/webp 或超过 20MB 的图——显示纯文件名）。
- **直链分享**（对象存储模式且管理员开启预签名时显示）：点「**直链**」复制一个限时下载地址（默认 1 小时有效），可直接发给外部人员或贴到文档/聊天里，对方无需登录即可下载。到期后在本页重新点「直链」获取新地址。

## 五、删除文件

1. 点操作列「**删除**」→ 确认弹窗（提示物理文件将一并删除）。
2. 确认后列表移除，物理文件尽力清理。
3. 注意：
   - 删除是**立即生效**的（回收站功能没有），重要文件请先下载备份；
   - 秒传共用的内容（同租户同内容多记录）在最后一处引用删除前物理文件保留，其余记录下载不受影响；
   - 业务模块上传的附件（业务分类列有值的），删除前请先确认业务侧不再需要——部分业务模块存有自己的关联记录，删文件可能导致业务页附件打不开。

## 六、文件管理员附加操作：「迁移历史文件」

（此按钮仅持存储迁移权限的角色可见，一般用户无需关注。）

平台/租户切换了存储模式后，点「迁移历史文件」把**本租户**的历史文件从旧存储搬到当前存储（平台管理员执行则为全库范围）。弹窗会显示迁移方向与耗时提示——文件多时耗时较长，建议低峰执行；完成后列表存储列统一为新后端标签。详细运维语义见 [01-平台管理员](01-平台管理员.md) 第四节。

## 七、常见问题

| 现象 | 处理 |
| --- | --- |
| 上传失败提示超限 | 普通上传上限 100MB；更大文件用「大文件直传」（对象存储模式）或联系管理员调整上限 |
| 看不到「大文件直传」按钮 | 当前是本地存储模式；该能力仅对象存储模式提供 |
| 看不到「删除」按钮 | 该角色未授删除权限（建议只给文件管理员）；需要清理时找租户管理员 |
| 「直传中」很久不消失 | 直传未完成（可能中途断网失败）；重新上传即可，残留行不影响使用 |
| 直链复制的地址别人打不开 | 已过有效期（默认 1 小时），重新复制；仍打不开联系管理员确认预签名功能已开启 |
| 找不到别人传的文件 | 同租户内文件互相可见，用文件名/业务分类/时间筛选；确实没有说明对方未上传成功 |
| 跨租户的文件能下载吗 | 不能。文件按租户严格隔离，其他租户的文件在本页不可见也不可达 |
| 图片缩略图不显示 | 该类型不支持缩略图（svg/webp）或源图超过 20MB，不影响上传与下载 |
